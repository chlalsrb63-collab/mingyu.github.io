# 테일즈테일즈 월드맵에디터 — 사용 안내

맵을 그리고, 몬스터·NPC·문을 놓고, 퀘스트를 쓰고, 그림(에셋)을 게임에 넣는 도구예요.
프로그램을 몰라도 쓸 수 있게 만들었어요. 고친 것은 `game/data` 폴더에 저장되고,
**빌드**를 하면 게임에 들어가요.

> 화면 예시 (에디터를 검사할 때 찍는 사진, 내 PC에만 있음 — `game/shots_editor/`):
> `01-map.png` 맵 그리기 · `02-map-npc.png` NPC 고치기 · `03-town-door.png` 광장에 문 놓기 ·
> `04-check.png` 검사 · `05-quest.png` 퀘스트 · `06-npcs.png` NPC·대사 · `07-assets.png` 에셋 ·
> `08-preview.png` 쿼터뷰 미리보기 · `09-playtest.png` 게임에서 테스트

## 1. 켜기

1. 저장소 맨 위의 **`EDITOR.bat`** 을 더블클릭해요. (처음 한 번은 설치 때문에 1~2분 걸려요.)
2. 몇 초 뒤 브라우저에 **http://localhost:5190** 이 열려요. 안 열리면 주소창에 직접 적어요.
3. 다 쓰면 검은 창(EDITOR.bat 창)을 닫아요. 테스트용으로 켠 게임 서버도 같이 꺼져요.

처음 열면 **"처음 사용하기"** 안내가 나와요. 오른쪽 위 **? 처음 사용하기** 로 언제든 다시 볼 수 있어요.

## 2. 맵 탭

화면은 세 부분이에요: 왼쪽 **맵 목록·맵 정보**, 가운데 **맵 그림**, 오른쪽 **팔레트(또는 고르는 창)·검사·미리보기**.

### 맵 고르기·만들기
- **기본** 표시 = 게임이 자동으로 만드는 원래 맵(광장, 초원…). **새 맵** = 직접 만든 맵. **고침** = 직접 고친 기본 맵.
- **새 맵**: 이름(한글), 아이디(영어 소문자, 예: `lotus`), 테마, 크기를 정해요.
- **복제해서 편집**: 고른 맵을 새 아이디로 복사해요. 원래 맵은 그대로예요.
- **삭제**: 직접 만든 맵을 지우거나, 고친 기본 맵을 원래대로 되돌려요. (지운 파일은 `game/data/.backup`에 남아요.)
- 기본 맵은 처음엔 **NPC와 문만** 더할 수 있어요. 바닥·물체를 고치려면 위 안내줄의 **이 맵 직접 고치기**.

### 층과 도구 (숫자 키 1~9)
| 층 | 하는 일 |
| --- | --- |
| 1 바닥 | 풀·길·물·모래… 칠하기 (물·암벽은 못 지나가요) |
| 2 물체 | 나무·바위·울타리·집(4×3칸)·가로등·표지판… (물체 칸은 못 지나가요). 표지판 글씨도 여기서 |
| 3 몬스터 구역 | 끌어서 네모 → 오른쪽에서 몬스터, 마리 수, 정예 %, 등급 |
| 4 NPC | 칸을 눌러 놓기 → 이름, 역할, **모습 고르기**(동물·얼굴·색), 대사(12줄까지, `{n}` = 플레이어 이름) |
| 5 문 | 칸을 눌러 놓기 → 갈 맵, 도착 위치(작은 지도를 클릭) |
| 6 모닥불 · 7 이동의 돌 · 8 입구 · 9 필드 보스 | 칸을 눌러 자리 정하기 |

바닥·물체 도구: **붓(B)**, **사각형(R)** (Shift = 테두리만), **채우기(K)**, **지우개(E)**, **스포이트(I)**,
**선택(S)** → Ctrl+C 복사, Ctrl+V 붙여넣기, T 회전, Delete 지우기. 붓 굵기는 오른쪽 위에서.

화면: 마우스 휠 = 확대/축소, 오른쪽 버튼(또는 Space)을 누른 채 끌기 = 이동, F = 맵 전체 보기, G = 칸 선.
되돌리기 Ctrl+Z, 다시 Ctrl+Y (200번까지).

### 검사와 미리보기
- 오른쪽 **검사** 목록: 빨간 ✗ = 꼭 고쳐야 저장돼요, △ = 주의. 줄을 누르면 그 칸으로 가서 깜빡여요.
- **쿼터뷰 미리보기**: 게임과 똑같은 그림으로 맵 가운데를 보여 줘요. 고치는 동안 몇 초마다 새로 그려요 (**크게** 로 크게 보기).

### 저장과 테스트
- **저장**(Ctrl+S): `game/data/maps/<아이디>.json`에 저장. 기본 맵에 놓은 NPC·문은 `npcs.json`·`links.json`에 저장돼요.
- **게임에서 테스트**: 저장하고, 게임 서버를 켜고, 새 탭에서 이 맵(마우스가 있던 칸 또는 입구)에서 시작해요.
  먼저 그 게임 계정에 캐릭터가 하나 있어야 해요. 처음엔 30초쯤 걸려요.
- 새 맵으로 들어가는 문이 하나도 없으면 게임에서 갈 수가 없어요. 광장 같은 기본 맵을 열고 **문** 층에서 새 맵으로 가는 문을 놓으세요.

## 3. 퀘스트 탭
- **사이드 퀘스트**: 새 퀘스트 → 의뢰인 NPC(역할이 '퀘스트 의뢰'인 NPC), 제목·본문·완료 대사,
  목표(몬스터 잡기 / 아이템 모으기 / NPC와 대화 / 장소 찾아가기), 필요 레벨·선행 퀘스트, 보상(경험치·골드·아이템), 반복 여부.
- **메인 퀘스트**: 보통은 **기본 퀘스트 사용**. 바꾸려면 **직접 만든 메인 퀘스트** → 기본을 복사해서 표에서 고쳐요.
- **퀘스트 저장**(Ctrl+S) → `game/data/quests.json`.

## 4. NPC·대사 탭
모든 NPC가 한 목록에 있어요 (**맵** = 직접 만든 맵, **추가** = 기본 맵에 더한 NPC, **기본** = 원래 NPC, 볼 수만 있음).
고르고 대사를 고친 뒤 **저장**. **맵에서 보기** 로 그 자리로 가요. **기본 맵에 NPC 추가** 로 광장 등에 새 NPC를 놓아요.

## 5. 에셋 탭
`asset/` 폴더의 그림을 폴더별로 보고(확대·배경·이름 찾기), 고른 그림을 크게 보고, 같은 이름의 지금 코드 그림과 비교해요.
**이 그림을 게임에 넣기** = `import-art.mjs --install` (주인이 승인했고 `asset/CREDITS.md`에 출처를 적은 그림만!).
지금 코드 그림 목록은 먼저 `ASSETS.bat` 을 한 번 실행해야 보여요. 자세한 순서: **에셋 작업 순서 보기** (`asset/README.md`).

## 6. 빌드·테스트 탭
- **검사**: 저장된 데이터 전체를 게임 규칙으로 검사해요 (문 도착 칸, NPC 아이디 중복, 퀘스트 의뢰인…). 줄을 누르면 그 맵으로 가요.
- **빌드**: 게임 규칙 파일(`src/logic.js`)을 데이터와 함께 다시 만들고, 검사하고, 빠른 테스트를 돌려요. 성공하면 게임에 반영돼요.
- **게임 실행**: 게임 서버를 켜고 새 탭에서 열어요.
- 다 됐으면 바뀐 파일(`game/data/**`, `game/src/logic.js`)을 커밋해요 (AI에게 "에디터로 만든 것 올려 줘"라고 해도 돼요).

## 7. 안전장치
- 지우기·덮어쓰기·크기 줄이기 전에는 꼭 물어봐요.
- 저장 안 한 작업이 있으면 맵을 바꾸거나 창을 닫을 때 물어봐요.
- 저장 안 한 작업은 이 브라우저에 5초마다 임시 보관돼요. 다음에 열면 "불러올까요?" 하고 물어봐요.
- 저장할 때마다 이전 파일이 `game/data/.backup/` 에 남아요 (파일마다 최근 20개).
- 에디터는 내 컴퓨터(127.0.0.1)에서만 열려요. 다른 사람은 접속할 수 없어요.

## 8. 개발자용
- 서버: `game/scripts/editor-server.mjs` (`npm run editor`), 앱: `game/editor/`. 데이터 형식과 API: [SCHEMA.md](SCHEMA.md).
- 진짜 데이터를 건드리지 않고 시험하기: `EDITOR_DATA=<복사한 폴더> npm run editor` (빌드는 검사만, 테스트 실행은 막혀요).
- 자동 조작: `window.__E` 가 맵 탭의 상태예요 (Playwright로 칸 좌표 → 화면 좌표 계산에 써요).
