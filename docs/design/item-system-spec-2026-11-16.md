## 2. 오너 요청 (원문 요지, 2026-11-16)

1. **접두사 효과 대량 기획**: 디아블로·마비노기의 접두사 장비 특수 옵션을 참고해 **70종 이상**, 장비 종류별로 다양하게.
   **무기·반지·장갑 = 공격형**, **상의·하의·목걸이 = 방어형**. **같은 접두사 효과는 중복 적용 불가.** 일단 **전부 구현**, 밸런스는 나중에.
2. **보조 옵션(일반 줄) 3분류**: 공격형 / 방어형 / 보조형. **무기: 마법 = 공격형 1줄, 희귀 = 공격형 2줄, 전설·유니크 = 공격형 3줄까지.**
   유저는 공격형을 선호하므로 **공격형 보조 옵션은 어떤 장비에서든 최소 1줄은 반드시 붙게.**
3. **인챈트 스크롤**: 접두사는 **낮은 확률로 스크롤 아이템으로도 드랍**, 마을의 **인챈트 NPC**에게 가서 장비에 붙임.
   **희귀 이상만** 가능. **전설 이상**(전설·유니크)은 기존 접두사를 스크롤의 접두사로 **덮어씀**. **희귀**는 **랜덤 보조 옵션 1줄 추가 + 전설로 승급 + 접두사 추가**.
   **인챈트는 골드를 소모, 장비 아이템 레벨이 높을수록 비쌈.**
4. **인챈트 NPC 설정**: 이름 **지선**, **귀여운 햄스터**, **대장간에 상주**, **대장장이 볼칸(`smith`, `34-maps-world.js:231`)의 여동생**
   (오너는 "불칸"이라 적음 = 볼칸으로 이해).
5. 이름 접두어 규칙: 단순 보조 옵션 상승에는 접두어/접미어 없음. **강력한 별도 효과가 있는 장비만** 접두어 (예: [뇌명의] = 25 % 확률 번개).
6. **유니크 = 전설(고유 효과 있음) + 보조 옵션이 아주 강하게 붙는 장비.** 전설보다 약 10~15 % 강함 (이미 구현).
7. 이 개편을 **Codex와 협업해 밸런싱 + 추가 컨텐츠 기획**까지 (이 문서의 §5, §6).

## 3. 정해진 규칙 · 계약 (구현 시 지킬 것)

### 3.1 보조 옵션 분류 (요청 2)
현재 `AFFIX`(10-tables.js) 12종을 분류합니다 — `AFFIX` 행에 `cat` 필드 추가:

| 분류 | 키 |
| --- | --- |
| 공격형 (O) | `atk` 공격력 · `atkp` 공격력 % · `crit` 치명타 % · `critd` 치명타 피해 % |
| 방어형 (D) | `def` 방어력 · `hp` 최대 HP · `ls` 흡혈 % (생존으로 분류) |
| 보조형 (U) | `mp` 최대 MP · `spd` 이동속도 % · `xp` 경험치 % · `mf` 아이템 발견 % · `gold` 골드 획득 % |

**공격형 줄 수 표** (부위 × 등급, 상수 표 하나로 조정 가능하게 `AFF_O_QUOTA`):

| 부위 | 마법(2줄) | 희귀(3줄) | 전설·유니크(4줄) |
| --- | --- | --- | --- |
| weapon 무기 | 1 | 2 | 3 |
| gloves 장갑 | 1 | 2 | 2 |
| ring 반지 | 1 | 1 | 2 |
| armor·helm·boots·amulet | 1 | 1 | 1 |

- 남은 줄은 방어형·보조형 풀에서 뽑되 방어 부위(armor/helm/boots/amulet)는 방어형이 잘 나오게 가중치. 한 장비에 같은 키 두 번 금지.
- **어느 장비든 공격형 ≥ 1줄** (새로 얻는 장비 기준; 이미 가진 장비의 줄은 그대로).
- 숫돌 재굴림(`58-life.js`의 `rollLine` 사용부)은 **줄의 분류 유지**. 인챈트(희귀→전설)로 추가되는 줄은 **새 등급의 공격형 쿼터가 모자라면 공격형**으로 채움.
- 정보창: 각 줄 옆에 분류 색 점/글자(공 · 방 · 보)를 작게.
- 공격형이 4종뿐이므로 무기 3줄 = 4종 중 3종. **새 공격형 키(공격속도 %, 스킬 피해 %, 정예·보스 피해 % 등)를 추가할지는 §6 기획 항목** (스탯 연결 필요).

### 3.2 접두사 풀 · 중복 방지 (요청 1) — 세부는 `prefix-effects.md` §1, §6
- 풀: 무기(W)·반지(R)·장갑(G)=공격, 상의(A)·하의=신발(B)·목걸이(N)=방어, 투구(H)=방어+유틸 혼합. `rollGear`는 부위 풀에서 등급(S1·M2·L1) 가중치로 선택. 접두사는 **전설(q3)·유니크(q5)만** 가짐.
- **중복 불가**: 같은 `lg` 키를 가진 장비를 여러 개 입어도 **아이템 레벨이 가장 높은 1개만 적용**(동률이면 `SLOTS` 순서가 앞선 쪽). 지는 쪽은 정보창에 회색 "중복 적용되지 않음". 전송 필드 `self.lgOff`(슬롯 이름 배열).
- 옛 장비는 풀 제한과 무관하게 계속 유효 (슬롯 글자는 "굴릴 때"만 제한).

### 3.3 인챈트 (요청 3 · 4)
- **스크롤 아이템**: 접두사 키마다 1종 `es_<key>` (예: `es_chain` "뇌명의 인챈트 스크롤"). `LEGEND`에 키가 추가돼도 자동으로 생기도록 **모든 파트가 로드된 뒤(늦은 파트)에 `ITEMS`를 생성**. `on`(구현 완료 표시)인 키만 드랍. 스택은 id 기준(룬과 같은 방식). 아이콘은 분류색(공격 빨강 · 방어 파랑 · 유틸 초록) 두루마리.
- **드랍**: 낮은 확률 — 일반 몬스터 ≈ 0.05 %, 정예 ≈ 0.4 %, 우두머리/균열 보스 ≈ 2 %, × (1+MF) 가량(조정 가능 상수). 어떤 키가 나올지는 키 전체에서 등급 가중치로. 상한·희소성은 §5에서 점검.
- **적용 조건** (`validateAction`): 대상은 **희귀(q2) 이상** 장비(세트(q4)는 제외 — 세트 정체성 때문; 오너 결정 대기), 스크롤 키의 **슬롯 글자가 그 장비 종류를 허용**해야 함(예: 방어형 접두사는 무기에 불가), 이미 같은 키면 거절("이미 같은 접두사"). 일반·마법은 거절 ("희귀 이상 장비에만 쓸 수 있습니다").
- **효과**: 전설·유니크 → `lg`만 교체(등급·줄·`il`·강화·소켓 유지, 유니크는 유니크로). 희귀 → `q:3`으로 승급 + **랜덤 보조 옵션 1줄 추가**(3→4줄, 새 줄은 전설 강도 ×1.3, §3.1 규칙으로 분류 선택) + `lg` 부여. 스크롤 1개 소모.
- **골드 비용 = 장비 아이템 레벨 비례**: 상수 표 `ENCH_FEE`(il 구간별 또는 부드러운 함수). 기준: **같은 단계 장비 제작 수수료보다 싸게**(`GEAR_CRAFT.fee 0.29 × 가격`, `12-life-tables.js`), 사냥 골드 ×0.4·알바 중심 경제(`economy-review-2026-11-15.md`)와 맞춰 il 200에서 알바 한두 번 분량. 창에 미리 표시, 서버가 검증·차감.
- **NPC 지선**: 대장간(캉캉대장간 내부 또는 볼칸이 있는 대장간 구역 — 데이터에서 볼칸/대장간 위치 확인) 상주. 햄스터 외형(`species.js` 햄스터), 말투는 귀엽고 야무진 동생, 대사에 "볼칸 오빠" 언급, 볼칸 쪽 대사에도 동생 한 줄(싸면). 직업/역할 `enchant`. 새 창(`win_enchant.js` 등): 가방/착용 장비 선택 → 스크롤 선택 → **결과 미리보기**(새 이름·바뀌는 줄·덮어쓰는 접두사·비용) → 확인. 새 행동 `ench`, 저장 시트 모양은 바뀌지 않음(아이템 필드만).
- 거래·창고·판매: 스크롤은 거래/창고 가능, 판매가는 낮게.

## 5. W4 밸런스 패스 (Codex)

목표: "일단 다 구현" 상태를 **플레이 가능한 수준**으로. 오너는 "밸런스 문제는 나중에" — 지금부터가 그 "나중"입니다.
- **효과 강도**: 접두사마다 `prefix-effects.md` §1의 기준(1P ≈ +17.6 % 피해 = 질주의, 1D ≈ −15 % 받는 피해)으로 S/M/L을 **시뮬레이션으로 확인**.
  `scripts/bench-tick.mjs`, 균열(레이드던전) 봇 파티(`tests/dimrift.mjs`), `balance-probe`의 고정 아레나를 활용해 효과 있음/없음 DPS·생존 차이 표 작성 → 범위를 벗어난 효과 수치 조정. 기록은 `docs/design/balance-items-2026-11.md`.
- **상한**: 카테고리 상한(`prefix-effects.md` §5)이 실제로 최악 조합(공격 4 + 방어 4)에서 작동하는지 테스트.
- **경제**: 단련의(추가 강화석), 약탈의(추가 골드)와 스크롤 드랍률, 인챈트 수수료가 `economy-review-2026-11-15.md`의 골드·강화석 수도꼭지와 충돌하지 않는지. 오너 정책: 사냥 골드 ×0.4, 알바가 주 수입, 45시간 Lv.200, 6단계 장비 Lv.181.
- **유니크/전설 드랍률**과 스크롤 드랍률의 체감: 시간당 몇 개인지 추정(몹 수 × 확률). 제안값을 보고서에.
- 직업 정책 주의: **도적은 광역이 없고 단일 대상이 강한 것이 의도**(메모리 `thief-single-target`) — 도적에게 광역 접두사가 지나치게 유리하지 않게. 칼날 소용돌이 3마리 유지. 직업 추가는 오너만.

1. **새 공격형 보조 옵션 키** (공격속도 %, 스킬 피해 %, 정예·보스 피해 %, 관통, 마나 흡수 …)와 그것을 스탯에 연결하는 방법, 방어/보조 쪽 부족한 키.
2. **스크롤 입수처 다양화**: 균열(레이드던전) 보상 상자, 주간 레이드, 알바 보상, 업적, 상점(비싼 고정가?), 스크롤 분해/합성. 희소성 곡선.
3. **인챈트 확장**: 옵션 재굴림 NPC 서비스(줄 하나 선택 재설정, 비용), 접두사 추출(장비 → 스크롤, 장비 파괴), 인챈트 기록 도감.
4. **유니크 전용 요소**: 유니크만의 외형(이름 색·아이콘 테두리·드랍 연출), 유니크 세트? 사냥 목표(도감/업적/칭호).
5. **아이템 레벨 200 엔드게임 싱크**: 골드·강화석 소비처, 아이템 레벨 최대치 구간 보상 정리.
6. 접두사 **테마 세트**(같은 계열 3개 이상 착용 시 보너스 — 중복 금지 규칙과 충돌하지 않는 방식) 가능성.
7. 지선·볼칸 **NPC 스토리**(남매, 대장간 일화)와 의뢰 아이디어 (실제 스토리 확정은 오너 결정, 열린 질문 건드리지 않기: 오래된 주문을 깨운 존재, 도톨/갈피, 일곱 별 표식, 리나의 부모).
8. UI/UX: 인챈트 창, 스크롤 아이콘, 옵션 분류 표시 개선안, 접두사 중복 경고 표시.
