# UX audit — 2026-11-15 (client HUD and windows)

Owner's order: "유저 친화적 UI/UX 개선 작업이 아주 중요해. 사소한 디테일도 신경써서 챙겨줘."
Method: read `game/public/` (items, win_char, windows, hud, quickslots, events, sxwin, housing, hud.css)
and played the live game at 960×600. References are conventions from MapleStory (M), Lost Ark (LA),
FFXIV (FF), WoW (W), Mabinogi (Ma) — not copies. Status: **fix** (done on this branch), **defer**
(worth doing, larger), **ok** (already there; listed so nobody re-builds it).
