# 버드나무마을 아르바이트

버드나무마을은 버드나무광장 피난민에게 식량과 수리 자재를 대는 생산 거점이다. 플레이어는 연못과 밭에서 재료를 얻고, 작업장과 부엌에서 가공하고, 마을 밖으로 보급품을 보낸다. 같은 주문도 재료를 캐는 사람, 재고를 납품하는 사람, 운송하는 사람에게 서로 다른 일로 보인다.

확장 맵이 `main`에 합쳐진 뒤 입구, 게시판, 연못, 부엌, 수리대, 집하장의 좌표와 길을 고정한다. 이 문서의 시간은 동선을 재기 전의 목표다. 기존 촌장 버들(`willow_elder`), 낚시꾼 갈대(`willow_fisher`), 꽃집 아이 봄이(`willow_florist`), 음유시인 솔(`willow_bard`)의 ID는 유지한다.

## 지급 기준

- **현행 기준을 공유한다.** 개인 게시판은 06:00 KST에 갱신되며 캐릭터당 하루 3건을 지급한다. 같은 게시판에 등록되는 마을 주문도 이 한도를 쓴다. 새 시설에서 수락하더라도 보상 횟수와 진행 상태는 동일하다.
- **보드는 생업별로 골라 일할 수 있어야 한다.** 자격을 갖춘 사람에게 현장 작업과 납품·배달을 섞어 제시한다. 날씨 의뢰를 놓쳐도 평소 주문을 선택할 수 있다. 한 의뢰의 재료를 스스로 구하거나 다른 생활 분야가 만든 재고로 충당할 수 있다. 직접 작업해야 하는 의뢰는 수락 뒤 서버가 기록한 작업만 인정한다.
- **현재 골드 단위를 따른다.** `856a159` 이후 보통 전 기본 지급은 일반 `120 + 24×숙련`, 배달 `80 + 16×배달 숙련`이다. 쉬움/보통/어려움 배율 1/1.6/2.5, 단골 10%와 기존 긴급·시간 보너스를 쓴다. 예를 들어 신뢰·시간 보너스 전 숙련 20 보통 납품은 960G, 보통 배달은 640G다. 추가 골드 배율은 실제 동선 측정 뒤 결정한다.
- **순수익으로 비교한다.** 납품 보수에서 재료의 상점 매각가 또는 실제 구매가와 제작 수수료를 빼고, 마을에서 수락해 보고하는 시간까지 잰다. 승인된 대안 동선을 포함해 활동 구간별 생활 의뢰 순수익 목표를 같은 시간 필드 사냥의 1.2~1.6배로 둔다. 현행 사냥 골드 0.4배는 처치 골드에 적용되며 장비 매각 수입은 별도로 측정한다.
- **골드와 물자는 다르게 센다.** NPC가 지급한 골드는 발행량, 다른 플레이어 재료를 사는 골드는 이전량이다. 주간 조정 때는 조건별 완료율, 지급액, 소모품 소비율, 협동 근무의 추가 수입을 따로 집계한다. 상점 구매→즉시 납품의 무위험 차익이 다른 의뢰를 앞지를 경우 해당 주문의 단가나 품목을 조정한다.

1. **시설·동선 확정.** 클로드의 확장본에서 연못·꽃밭·부엌·수리대·집하장과 광장 출입문을 확인한다. 시간대별 NPC 위치에서도 접수와 보고가 가능한지 확인한다.

3. **현장 작업과 공급망 추가.** 모듈별로 위 주문에만 서버 체크포인트를 붙인다. 이동의 돌과 귀환 주문서를 포함한 최단 경로를 잰 뒤 배달 제한 시간을 정한다. 지역 간 빠른 이동을 쓸 수 있는 계약과 도보 운송 계약은 안내에서 구분한다. 필요하면 버드나무마을의 합동 출하를 별도 협동 근무로 설계한다.
