# 맵별 BGM 방향

타이틀에서 모험의 기대감을 만들고, 마을에서는 장시간 머물러도 편안하게 한다. 필드는 각 공간을 구분할 수 있게 하고 발소리, 공격음과 전조음을 위한 여유를 둔다. 테마가 반복될 때 멜로디 밀도나 반주를 바꾼다.

| 키 | 장면 | 템포·조성 | 중심 소리와 편곡 |
| --- | --- | --- | --- |
| `title` | 타이틀 | 140 BPM · D장조 | 전기 피아노 도입, 하프타임 드럼과 스테레오 신스 코드가 들어오는 퓨처베이스 후렴 |
| `town` | 넥서스 광장 | 82 BPM · F장조 | 낚시터와 장터에 어울리는 전기 피아노, 7화음, 살짝 밀리는 로파이 드럼 |
| `willow` | 버드나무 마을 | 82 BPM · F장조 | 맵 설정의 `bgm: town`으로 넥서스 광장 곡을 이어서 사용 |
| `meadow` | 바람초원 | 114 BPM · G장조 | 가벼운 플루트와 뜯는 현, 앞으로 나아가는 박자 |
| `forest` | 속삭임 숲 | 78 BPM · D 도리안 | 짧게 응답하는 플루트와 드문 종소리, 길게 남는 패드 |
| `crypt` | 뼈의 지하묘지 | 66 BPM · C단조 | 낮은 오르간 선율, 긴 울림과 묵직한 종 |
| `city` | 네온 시티 | 116 BPM · A단조 | 싱코페이션 아르페지오와 전진하는 신스 베이스, 전기 피아노 브리지 |
| `sewer` | 하수도 | 93 BPM · G단조 | 비틀린 킥과 스네어 박자, 물방울 사이에 짧은 건반음 |
| `cave` | 수정 동굴 | 65 BPM · E단조 | 음 사이가 넓은 수정 종, 물방울과 길게 남는 반향 |
| `abyss` | 피의 심연 | 72 BPM · D 프리지안 | 불규칙한 심장박동, 반음과 증4도로 불안감을 주는 저음 |
| `boss` | 우두머리 출현 | 148 BPM · E단조 | 기존 전투 테마, 긴박한 펄스와 빠른 드럼 |
| `rift` | 균열 이벤트 | 138 BPM · F♯단조 | 기존 이벤트 테마, 신스와 빠른 아르페지오 |

## 참고 영상

- 광장은 항구 휴식과 로파이라는 제작자 설명을 참고했다. [느린달팽이 · 항구에서 휴식하며 듣는 테일즈위버 커버](https://www.youtube.com/watch?v=G9yKuGwnIBs)

두 트랙의 멜로디와 화성은 테일즈테일즈용으로 작곡했다.
