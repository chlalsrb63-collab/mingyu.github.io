# Antigravity 복사용 · 작은꼬리 64×64 외형 장비

```text
테일즈테일즈의 코드 기반 픽셀 아트로 작은꼬리 외형 장비 두 세트를 제작해 줘.
네 작업 폴더는 .work/gemini, 브랜치는 gemini/work다. AGENTS.md §4·§6~8과 ai/gemini.md §5, ai/prompts/cosmetic-assets.md의 외형·검수 절차를 읽어. 이 메시지가 한 개의 직접 지정 [ART] 작업이다.
먼저 game/public/sprites.js에서 캐릭터 프레임이 실제로 64×64를 반환하는지, game/public/wardrobe.js에서 0.5 논리 좌표를 받는지 확인해. 해당 변경이 작업 폴더에 없으면 브랜치를 임의로 바꾸거나 재구현하지 말고, 아래 초안을 아트 명세와 64 도트 레이어로 준비해.

1. 등불 나루 구조대 (기름먹인 청록 천·황동·주황 신호색)
   - 물막이 챙모자: 낮은 이중 챙과 옆의 짧은 턱끈. 눈과 귀가 보이게.
   - 등불지기 방수복: 짧은 겹깃, 옆구리까지 내려오는 주황 구조끈, 작은 황동 매듭.
   - 조난등 반망토: 한쪽 어깨 고정, 비에 젖은 아랫단과 길게 세로로 붙은 반사 띠.
   - 황동 물안경: 호박색 옆테와 청록 렌즈 가장자리. 이마와 눈을 뒤덮지 않게.
2. 설맥 관측소 (미색 누빔·자줏빛 양모·빙청 유리)
   - 별바늘 귀덮개모: 앞에서 뿔처럼 읽히지 않게 별금속 단추 두 점과 각진 방한 귀덮개.
   - 별자리 누빔옷: 미색 겹섶, 자주색 가슴끈, 한 방향으로 이어지는 굵은 솔기.
   - 눈바람 측량 망토: 뒤로 갈라진 두 폭과 삼각 지도 주머니. 보행 때 밑단이 가볍게 움직임.
   - 빙청 반무테 안경: 반짝임은 렌즈 바깥 모서리 1도트. 눈동자가 그대로 보이게.

프레임은 64×64 네이티브 도트이고 월드에서 몸 크기·발 기준점·표정·종족별 실루엣은 기존과 같다.
기존 좌표 단위와 실제 캔버스 픽셀을 구분해. 논리 좌표가 기존 32단위라면 0.5가 새 도트 한 칸이다.
잊지 말아야 할 착용 조건은 귀와 뿔·개구리 돌출눈의 레이어 순서다. 얼굴·털을 통째로 새로 그리지 마.
기존 외형 ID·팔레트·레이어 등록 규약을 참고하고, 새 장비마다 모자/상의/등/얼굴과 일관된 앞·옆·뒤 실루엣을 만들어.
잘 보이는 큰 형태를 잡은 뒤 64 격자로 챙 모서리·솔기·버클 정도만 세밀하게 다듬어. 계단식 픽셀, 불투명 면, 투명 여백, 어두운 외곽선, 한 방향 조명. 흐림·안티앨리어싱·외톨이 픽셀은 쓰지 마. 참고 자산은 형태와 색 공부에만 쓰고 직접 복제하지 마.

코드 좌표·팔레트와 착용 가이드는 ai/proposals/gemini-cosmetics-64.md에 정리해. 8품목마다 영문 ID, 한국어 이름, 슬롯, 재질, 앞/옆/뒤 모양, 앵커·가림 처리, 장착 위치, 16×16 가방 아이콘 구도, 획득 제안(버드나무토큰 또는 보스)을 넣어.
호환되는 64 렌더러가 있다면 실제 캐릭터에 입힌 미리보기를 만들고 기본형·토끼·개구리·뿔 있는 종족에서 정면/측면/후면, 서기와 걷기, 게임 크기와 확대를 확인해. 두 세트를 최대 2장에 담아.
외부 생성 PNG를 쓴 경우 asset/generated/cosmetics-64/에 원본과 .prompt.md를 두고 asset/CREDITS.md에 출처를 적어. import-art.mjs가 받아들이는 아이콘이나 시트만 검수용으로 정규화하고, 레이어 시안은 64×64 투명 원본을 유지해. --force, --install은 사용하지 마.

game/src/logic/, 저장 데이터, 스냅샷, 실제 상점 가격은 건드리지 마. 다른 에이전트가 진행 중인 64×64 캐릭터·NPC 리뉴얼을 덮어쓰지 마.
바꾼 JS는 node --check, 착용 결과는 직접 열어 검토. ai/reports/gemini-cosmetics-64.md에 대표 PNG 경로와 품목별 검수 결과, 적용하려면 수정할 파일과 순서, 남은 작업을 적어.
변경한 경로만 stage해서 gemini/work에 커밋해. push, rebase, main 병합은 하지 마.
```
