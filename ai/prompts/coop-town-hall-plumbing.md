# 구현 프롬프트 · 마을회관 배관이 터졌어요!

테일즈테일즈의 버드나무광장 회관에 협동 아르바이트 **「마을회관 배관이 터졌어요!」**를 구현해 줘.

> 오래된 회관의 수도관이 또 터졌어요. 바닥에 물이 차기 전에 급수구부터 배수구까지 이어 주세요. 연결 작업은 양쪽에서 시작해야 해요.

## 입장과 한 판 흐름

- 버드나무광장 회관(`town_hall`)에서 포포(`popo`)에게 말을 걸어 시작한다. 기존 개인 알바 메뉴와 함께 **협동 배관 수리**를 보여 준다. 같은 회관에 모인 2~4인 파티의 파티장만 시작할 수 있다. 기존 협동 알바 대기·입장·결과·퇴장 흐름을 사용한다.
- 기존 협동 인스턴스 안에서 팀 모두가 같은 **32×32 배관 보드**를 본다. 안내가 끝나면 서버 기준으로 5분이 흐른다. 5분 이내에 서로 맞물린 배관으로 급수구와 배수구를 이으면 바로 성공한다.
- 열 0~15는 **급수 담당**, 열 16~31은 **배수 담당**이 편집한다. 2인은 1+1, 3인은 2+1, 4인은 2+2로 배정한다. 급수구와 배수구 양쪽에서 미리 이어 놓을 수 있으며, 중앙 경계에서는 동·서 연결구가 마주할 행을 맞춰야 한다. 양쪽 담당의 서로 다른 플레이어가 놓은 조각이 최종 경로에 들어가야 성공한다.

## 배관과 바위

| 조각 | 연결되는 방향 | 그림 |
| --- | --- | --- |
| 세로 일자 | 북↔남 | │ |
| 가로 일자 | 서↔동 | ─ |
| ㄱ자 | 서↔남 | ┐ |
| ㄴ자 | 북↔동 | └ |

- 각 플레이어는 위 네 종류 중 무작위 배관 한 개를 손에 든다. 담당 구역의 빈 칸에 설치하면 다음 도구를 받는다. **회전, 버리기, 손 교환, 설치한 조각 회수는 금지**한다. 자기 구역 안에서는 현재 물줄기와 떨어진 빈 칸도 쓸 수 있으므로, 나중에 필요한 곳에 먼저 놓을 수 있다.
- 시작할 때 전체의 약 **55%를 바위**로 채우고, 일부는 덩어리로 배치한다. 후속 도구의 약 **5%는 배관 대신 1회용 망치**다. 망치로 담당 구역의 바위 한 칸을 깨면 다음 배관을 받는다. 급수구·배수구·이미 설치한 배관은 망치 대상이 아니다. 연속 망치 지급을 피하고, 받을 때 자기 구역에 대상이 없으면 배관을 지급한다. 지급 후 다른 팀원이 마지막 바위를 깼다면 들고 있는 망치는 서버가 배관으로 교체한다.
- 재시도 때마다 시드로 판을 바꾼다. **서쪽 급수구에서 동쪽 배수구로 가는 동·남 방향의 해답 경로를 먼저 생성**하고, 그 경로에 필요한 조각을 네 종류만으로 표현할 수 있는지 검사한다. 배수구는 급수구보다 아래에 두고, 해답의 중앙 경계 통과 좌표도 판마다 바꾼다. 경로 밖에 바위와 여유 칸을 배치한다.
- 구역별로 숨겨진 해답에 필요한 조각의 개수를 확보한 뒤, 섞은 지급 목록에 소량의 여분 조각을 넣는다. 같은 구역 담당자끼리는 한 목록에서 뽑는다. 여분 조각을 놓을 빈 칸이 충분한지 생성 시 검사한다. 망치가 지급되는 경우에는 배관 목록을 그대로 두고, 사용 후 배관을 한 개 뽑는다. **망치 없이도 풀 수 있는 판**을 보장한다. 망치는 지금 가진 조각에 맞춰 새 통로를 내는 데 쓴다. 서버만 해답과 지급 목록을 보관한다.

## 성공·보상

- 급수구에서 시작해 서로 마주 보는 연결구만 방문한다. 서버에 등록된 배수구에 도달하고 양쪽 담당의 실제 설치가 확인된 순간 성공한다. 시간 종료나 한쪽 담당만의 설치는 미달이다. 이동한 거리나 아무 칸에 놓은 배관 수는 클리어 점수에 넣지 않는다.
- 현재 협동 알바 등급에 맞춰 **C는 연결 성공, B는 남은 시간 45초 이상, A는 90초 이상, S는 135초 이상**을 초안으로 사용한다. 실패는 0등급이다. 완성 경로에 놓은 조각과 경로 위에서 깨 준 바위로 개인 기여를 집계한다. 한 사람이 전부 플레이하거나 구석에 조각을 채우는 방식으로 정규 보상을 받을 수 없게 한다.
- 근무지별 첫 정규 지급, 06:00 KST 초기화, 재도전 수고비는 공용 `coopPay`를 사용한다. 생활 숙련은 제작/대장에 연결한다. 현재 지급 규칙에 따라 첫 정규 보상의 버드나무토큰 2개도 적용한다. 성공 판정과 지급은 한 판에 한 번이다. 근무지의 S 기록을 추가할 경우 신규·기존 시트의 카운터 초기화와 정규화를 함께 처리한다.
- 남은 1분에는 바닥 물이 차오르는 연출과 경고음을 넣는다. 시간·등급 계산은 위 표를 쓰며, 이 근무지의 피버가 임의로 보상 배율을 올리지 않도록 공용 점수형 피버와 구분한다.

## 구현 경로와 UI

- 먼저 `AGENTS.md`, `docs/design/life-and-coop.md` §C와 §H7, `12-life-tables.js`의 `COOP`, `68-coop.js`의 `COOP_JOB`·`coopValidate`·`coopApply`·`coopView`를 확인한다. 기존 협동 알바에 `pipe` 키로 추가하고, 클라이언트는 `game/public/coop.js`의 진입·결과 창과 연결한다. 생성 로직인 `game/src/logic.js`는 빌드 명령으로 갱신한다.
- 설치와 파괴는 하나의 보드 행동으로 받고, 서버가 현재 손에 든 도구로 결과를 해석한다. 예시 입력은 `{t:"coop_act", i:셀인덱스, handRev:손패버전}`이다. 다른 알바의 입력 계약은 기존대로 보존한다. 서버에서 인스턴스·좌석·시간·좌표·구역·칸 상태·손패 버전을 검증한다. 실패한 입력에는 손패 차감이나 다음 도구 지급이 없다. 동시 클릭이나 중복 요청에도 설치와 지급은 한 번만 일어난다.
- 접속이 끊겨도 제한 시간은 흐르고, 남아 있는 같은 구역 팀원이 작업할 수 있다. 역할을 실시간으로 넘겨 한 사람이 양쪽을 채우는 동작은 금지한다. 기존 재접속 흐름이 인스턴스 복귀를 지원한다면 그 좌석의 손패와 기여도도 복원한다.
- 최초 보드 상태와 이후 변경 칸을 버전과 함께 보내고, 바뀐 칸이 없는 재전송에는 1024칸을 담지 않는다. 손패 정보는 자기 것과 팀 협의에 필요한 보이는 단계만 공개한다. 남은 시간을 서버 기준으로 표시하고 입장·퇴장 시 보드 입력을 정리한다.
- 코드로 그린 낡은 회관 바닥, 청동 배관, 회색 바위, 급수 밸브와 배수구를 사용한다. 첨부 사례는 열린 관 끝과 물 흐름의 가독성만 참고한다. 급수구에서 이어진 관에는 푸른 물결 표시를 추가하고, 막힌 끝과 성공 표시는 색과 윤곽으로도 구별한다. 설치·바위 파괴·성공 효과음을 마련한다.
- 화면에 역할, 팀원 손패, 타이머, 급수구·배수구를 표시한다. PC는 클릭 또는 방향키와 확인 키로 둔다. 모바일은 확대·이동과 칸 선택 후 설치를 지원하고 드래그 중에는 설치를 막는다. 화면 전체 보기와 확대 상태 양쪽에서 중앙 경계를 확인할 수 있게 한다.

## 완료 기준

1. 여러 시드의 2·3·4인 판에서 바위 비율, 조각 목록, 망치 없이 5분 안에 완주 가능한 입력 순서를 규칙 테스트로 검증한다. 회전·폐기 시도, 다른 구역 입력, 막힌 포트, 한쪽만 설치, 동시 클릭, 중복 요청, 시간 초과, 참가자 이탈도 확인한다.
2. 실제 2인 플레이에서 급수 구역과 배수 구역을 동시에 작업해 연결을 완료한다. 3·4인 보드 동기화와 모바일에서의 확대·설치를 검수한다. 성공·실패·같은 날 재완료·06:00 이후 재완료에서 보상 차이를 확인한다.
3. `npm run build:logic`, `npm run data:check`, `npm run test:rules`를 실행한다. `ai/reports/`에 게임 진입 경로, 최종 수치, 실제 검수 결과와 대표 화면을 남긴다.
