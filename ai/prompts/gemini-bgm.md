# 테일즈테일즈 · Gemini 작곡 프롬프트

각 지역의 완성형 프롬프트는 [고정 맵 30개와 타이틀·전투 음악 목록](gemini-map-bgm.md)에 있다. 이 문서는 광장용 상세 프롬프트와 음원 적용 방법을 담았다.

## Gemini에 붙여넣을 내용

```text
테일즈테일즈라는 한국 쿼터뷰 온라인 RPG의 첫 공식 사운드트랙을 작곡해줘. 플레이어는 작은 동물 모험가로 버드나무광장에 모여 파티를 꾸리고, 바람초원과 속삭임 숲을 지나 균열의 근원을 조사해. 수십 분씩 머무는 필드와 마을에서 매일 들어도 기억에 남는 연주곡이 필요해.

이번 곡의 ID는 town, 장면은 버드나무광장이야. 늦은 오후, 버드나무 아래 시장이 문을 닫기 시작하고 사냥을 마친 동료들이 광장으로 돌아올 때의 음악으로 만들어줘. 환대와 그리움을 함께 담되, 무겁거나 졸리지 않게 해줘.

테일즈위버의 맑고 서정적인 모험 감성과 바람의나라의 짧고 오래 기억되는 지역 테마를 분위기 참고로 삼아줘. 7th/add9 중심의 색채 있는 코드 진행, 질문과 응답이 있는 프레이즈를 사용하고 기존 OST의 멜로디·사운드·샘플은 재현하지 말아줘. 선율을 두 번 듣고 흥얼거릴 수 있을 만큼 간결하게 쓰고, 두 번째 등장에서 마지막 음이나 화음을 바꿔줘.

84–90 BPM, 4/4, 따뜻한 장조에 짧은 단조 전환. 자연스러운 어쿠스틱 그랜드 피아노의 아르페지오와 손끝 강약이 중심. 나일론 기타 또는 하프의 뜯는 소리, 얇은 실내악 현, 숨이 들리는 플루트나 대금 계열의 목관으로 응답. 라운드한 베이스와 브러시 퍼커션은 낮게. 신스가 있다면 거의 느껴지지 않는 공간층으로만. 보컬, 합창, 말소리, 8비트·GBA풍 음색, 사각파 리드, 칩튠 드럼, EDM 드롭, 과장된 웅장함, 현장 효과음은 제외해줘.

도입 4마디 → A 16마디(주제) → B 12–16마디(목관 답구와 화성 전환) → A′ 16마디(주제 회귀) → 첫 코드로 연결. 첫 12초 안에 훅을 들려주고, 중반은 대화와 효과음이 앉을 공간을 남겨줘. 사운드는 모던하고 따뜻하게, 밝은 악기 하나가 앞에 서고 나머지는 악기 사이 간격이 들리게 편곡해줘. 목표 길이는 약 2분 20초에서 2분 50초인 인스트루멘털이야.

게임에서 한 구간을 계속 반복할 거야. 반복 경계 쪽에 큰 필인, 엔딩 코드, 긴 페이드아웃이나 무음을 넣지 말아줘. 마지막 2마디에서 첫 화음으로 자연스럽게 연결해줘. 먼저 재생 가능한 음원 한 곡을 생성해줘. 다운로드할 수 있으면 오디오 전용 파일로 제공하고 권장 파일명은 town.mp3야. 출력에서 반복 시작/끝을 실제로 확인할 수 있는 경우만 초 단위로 적고, 확인할 수 없다면 마지막으로 돌아가기 직전의 반복 후보 마디를 표시해줘.

내 로컬 저장소를 열거나 수정할 필요는 없어. 답에 곡 제목, BPM과 박자, 사용 악기, 반복 후보 구간을 짧게 남겨줘. 오디오 생성 기능이 없는 대화라면 같은 곡을 Lyria ‘음악 만들기’에 바로 넣을 수 있도록 위의 장면·편곡·루프 지시를 1개의 작곡 프롬프트로 정리해줘.
```

## 로컬 게임에 넣기

1. Gemini **음악 만들기**에서 **인스트루멘털**과 긴 길이를 선택하고 프롬프트를 붙여넣는다. 다운로드는 **오디오 전용 MP3**를 고른다. 계정에서 긴 길이가 열린 경우에 사용한다. [Gemini 음악 만들기 도움말](https://support.google.com/gemini/answer/16901237)
2. 받은 MP3를 `game/public/assets/music/`에 넣고 파일명을 맵 키로 맞춘다. 예를 들어 광장은 `town.mp3`, 타이틀은 `title.mp3`, 바람초원은 `meadow.mp3`, 속삭임 숲은 `forest.mp3`다. 단풍 왕도는 맵 ID인 `maple.mp3`를 쓴다.
3. [로컬 게임](http://127.0.0.1:8866/)을 새로고침하고 **뉴에이지** 편곡을 선택한다. 자동 등록된 MP3는 처음부터 끝까지 반복된다. 등록되지 않은 장면과 **클래식** 편곡은 기존 합성곡을 재생한다.

### 반복 구간이나 곡 음량을 별도로 지정할 때

무음과 엔딩 페이드를 덜어낸 음원이 가장 간단하다. 반복 시작과 끝을 직접 정하려면 `game/`에서 올바른 초를 지정해 등록한다. 등록한 항목은 같은 키의 단순 MP3 파일보다 먼저 재생된다.

   ```powershell
   npm run bgm:import -- "$env:USERPROFILE\Downloads\town.mp3" --track town --start 2.41 --end 128.36
   ```

위 시간은 입력 예시다. `--gain 0.65`가 기본이고 더 작게 조절할 수 있다. 예약 키는 `npm run bgm:import -- --list`로 확인한다. 같은 키의 설정을 바꾸려면 `--replace`를 사용한다. 별도의 야간 곡은 `--track town_night`로 등록한다.

가져오기 스크립트는 음원을 `game/public/assets/music/`에 복사하고 `game/public/assets/manifest.json`의 `bgm`에 등록한다. 로컬에서 다운로드를 넘기는 것으로 충분하다. 공개 빌드에 반영할 곡은 선정 후 원본, 장면 키, 생성 도구, 날짜를 `asset/CREDITS.md`에 기록하고 배포용 파일을 함께 반영한다. Gemini가 코드를 출력하는 쪽이 필요하면 음원 대신 16스텝 바 형식의 악보도 받을 수 있지만 게임의 합성 악기로 연주된다.
