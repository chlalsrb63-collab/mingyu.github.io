# Antigravity 작업 프롬프트 · 전투 이펙트와 장비 에셋

아래 코드 블록을 Antigravity의 `gemini/work` 작업 폴더에서 실행하는 채팅에 붙여넣는다.

```text
테일즈테일즈의 로컬 gemini/work 작업 폴더에서 작업해. AGENTS.md와 ai/gemini.md의 §5, docs/FILEMAP.md의 스킬 이펙트·장비 아트 행, .claude/skills/pixel-art/rules/의 실루엣·가독성·재질·아이콘 규칙을 읽어. git status로 깨끗한지 확인하고 Claude가 동기화한 현재 작업 트리에서 시작해. rebase, main 병합, push는 하지 마.

한 세션에 A, B 중 한 가지를 맡아. 첫 세션은 A를 하고, 결과물을 검수한 다음 새 세션에서 B를 진행해.

A [VFX] — 직업 Lv.3 주력기 중 참나무 횡베기(fx 137)·창날 쪼개기(139)·강철 발굽(143)의 이펙트를 검수하고 약한 컷을 다시 그려. 대검은 호 형태의 검기, 창은 끝점이 뚜렷한 직선 찌르기, 해머는 착지점부터 퍼지는 지면 파문을 써. 예비 동작·타격·소멸을 구분하고, 1배율에서 방향과 범위가 읽혀야 해. 큰 섬광을 반복하거나 보스의 바닥 전조를 가리지 않게 해. 먼저 game/public/skillfx.js와 events.js의 연결을 확인해. 이 직업기 코드가 아직 워크트리에 없다면 범위와 방향을 조절할 수 있는 독립 미리보기를 만들고 연결할 이펙트 번호를 보고서에 적어. 발동 타이밍·판정·서버 코드는 건드리지 마.

B [ART] — 장비 아이콘 12종을 두 테마로 나눠 제작해. 버드나무 정찰대는 이끼색 천·황동, 산호 항구 상단은 청록색 천·밝은 금속을 써. 테마마다 대검·창·해머·투구·갑옷·장갑 6종. 무기는 우상향 45도, 무기별 실루엣과 방어구 부위가 16×16에서 구분되어야 해. 1픽셀 외곽선, 투명 배경, 최대 16색, 단색 픽셀로 작업해. 외형 장비를 캐릭터에 입힌 모습과 가방 아이콘이 같을 거라고 가정하지 말고, 필요한 착용 슬롯·앵커·앞뒤 가림을 별도 메모해. 참고 그림은 분위기만 참고하고 베끼거나 덧대지 마.

AI 생성 초안은 asset/generated/scout-harbor-gear/에 프롬프트와 함께 두고 CREDITS.md에 출처를 적어. 게임의 import-art.mjs로 정규화하고 기존 에셋과 비교 이미지를 만들어. 이미 쓰는 파일은 덮지 말고 --force, --install은 쓰지 마. 코드 작업은 바꾼 JS에 node --check, 그림은 현재 렌더러에서 확대와 1배율을 함께 확인해. 미리보기 1~2장과 한국어 보고서 ai/reports/gemini-<작업>.md를 남겨. 서버 규칙·저장·통신·캐시 태그는 수정하지 말고, 바꾼 파일만 경로로 스테이징해 gemini/work에 커밋해.
```
