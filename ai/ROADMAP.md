# 콘텐츠 개선 로드맵 — AI 팀이 스스로 일을 고르는 곳

`ai/TASKS.md`에 자기 섹션의 할 일이 비어 있으면, 각 AI는 **이 파일에서 다음 일을 스스로 고릅니다**
(자동 개선 모드). 위에 있을수록 우선입니다. 끝난 항목은 Claude(병합 담당)가 `[x]`로 바꿉니다.
사람이 이 파일의 순서를 바꾸면 AI의 우선순위가 바뀝니다.

## 품질 기준 — 모든 콘텐츠 작업의 "완료" 조건

1. **규칙 테스트 통과** (`npm run test:rules`), 규칙을 바꿨다면 그 규칙을 검사하는 테스트를 추가.
2. **세계관**: 꼬리 달린 귀엽고 단순한 동물 친구들 vs 지옥에서 올라온 기괴한 짐승들. 밝고 아기자기한 마을·생활,
   어둡고 끔찍한 사냥터. 이름·대사는 한국어, 짧고 입에 붙게, 말장난과 귀여움 OK, 잔혹 묘사는 몬스터 쪽만.
3. **수치 근거**: 보상·확률·경험치는 기존 표(`10-tables.js`, `xpNeed`, `docs/balance.md`)와 비교해 근거를 보고서에 적기.
   한 번에 ±15% 넘게 바꾸지 않기.
4. **작게**: 한 작업 = 한 가지 개선, 파일 몇 개. 큰 기능은 Gemini가 3~6개의 작은 Codex 작업으로 쪼갭니다.
5. **기존 저장 데이터 보호**: 캐릭터 시트 필드 추가 시 `migrate` + 옛 시트 테스트 (AGENTS.md §4).
6. 그림·UI를 바꿨다면 `shot.mjs`로 **한 장만** 확인하고 보고서에 경로를 적기.
