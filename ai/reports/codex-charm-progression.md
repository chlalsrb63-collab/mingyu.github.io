# 참 등급색, 각인, 아이템 레벨

- `codex/charm-rune-blocks`에서 로컬 `main` `516e35c`를 병합한 뒤 작업했다.
- 매직·레어·전설은 장비와 공통으로 사용하는 파랑·노랑·주황 등급색을 사용한다. 한 조각 안에서는 룬 20종 중 서로 다른 문양이 각 칸에 새겨지고, 회전해도 문양이 각 칸을 따라간다.
- 획득처 티어의 표시 레벨 범위 상단을 기준으로 Lv.30·50·70·90·110·130·150·170·190·200 중 해당 단계로 내린다. 30 미만은 Lv.30이고, 장착 요건은 아이템 레벨 −10이다.
- 새 참은 2~4칸이며, 4칸 드롭은 세로·가로 막대, 정사각, ㅗ자, ㄴ자, 계단형을 포함한다. 첫 의뢰는 Lv.30 매직 2칸 참이다.
- 같은 옵션의 기본 굴림은 크기에 따라 ×1.7·2.3·2.9를 적용하고, 레벨 단계당 기준 수치의 8%를 더한다. 기존 보드 합산 상한을 적용한다.
- 이전 봉인의 원래 감정 결과와 보드 배치를 보존한다. 레벨이 부족한 배치 참은 효과가 정지되며 레벨을 다시 충족하면 활성화된다.

## 만진 파일

- `game/public/charms.js` · 룬 픽셀 아트, 보드와 가방 및 감정 화면, 장착 조건 표시.
- `game/public/items.js`, `game/public/hud.css` · 공용 파일. 참 슬롯, 참 카드, 보드 색상과 레벨 상태 표시만 수정했다.
- 구역 밖 수정 · 직접 요청받은 참 규칙 작업으로 `game/src/logic/66-charms.js`와 `game/tests/charms.mjs`를 수정했다. 생성본 `game/src/logic.js`는 `npm run build:logic`으로 갱신했다.
