# 맵별 BGM과 작곡 스킬

`game/public/bgm.js`에 타이틀과 맵 8곳의 루프를 작곡했다. 타이틀은 D장조 140 BPM 퓨처베이스, 넥서스 광장은 F장조 82 BPM 로파이다. 타이틀은 전기 피아노에서 하프타임 비트와 넓은 신스 후렴으로 넘어간다. 광장곡은 7화음과 살짝 늦는 드럼 위에 전기 피아노를 놓았다. 두 참고 영상에서 확인한 범위는 제작자가 공개한 설명과 곡 목록이다.

`.agents/skills/tales-tales-bgm/`에 [작곡 절차](../../.agents/skills/tales-tales-bgm/SKILL.md), [맵별 음악 방향](../../.agents/skills/tales-tales-bgm/references/maps.md), 렌더러를 뒀다. 기존 보스·균열 악보를 새 파일로 옮기고 원본과 값이 같은지 대조했다. 게임에서는 기존 음악 선택, 전환, 음량 경로를 사용한다.

- `npm run test:rules` 16/16 통과. 코드 길이·패턴 검사 및 스킬 폴더 검증 통과.
- `render-bgm.mjs --out game/shots/bgm`으로 11곡을 실제 Web Audio에서 두 바퀴씩 렌더링했다. WAV는 44.1kHz 스테레오다. 새 곡은 약 33–59초이고, 전곡 최대 피크는 0.537이었다. 렌더링과 수치 검증을 마쳤으며 전체 맵을 직접 플레이하며 청취하는 단계는 남아 있다.
- 로컬 라이브 타이틀에서 140 BPM 트랙의 오디오 컨텍스트가 실행 중임을 확인했다. `shot.mjs --live`로 광장 입장 뒤 82 BPM 곡 재생, 보스 테마 전환과 광장 복귀를 확인했다. 브라우저 오류는 없었다.
- 캐시 태그 네 곳은 `1795150042`로 갱신했다. WAV 11개와 타이틀·광장 MP3는 `game/shots/bgm/`에 있다.
