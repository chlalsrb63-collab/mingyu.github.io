# 장비 격차 2배와 전투 밸런스

- `codex/item-level-curve`의 기준 `main`은 `0e1e866`이다. 검 기준 강화 전 공격력은 Lv.1 `6`, Lv.181 `1,798`, Lv.200 `2,086`이다. 아이템 레벨 1→200의 표시 공격력 차이 `1,040→2,080`을 적용했다.
- `game/src/logic/10-tables.js`에서 필드 몬스터 HP와 공격력을 티어별로 재조정했다. 방어력에는 기존의 완만한 곡선을 사용해 낮은 장비도 피해를 줄 수 있게 했다. 첫 몬스터의 HP·공격력은 36·8이고, Lv.197 대표 몬스터는 HP 54,007→108,015, 공격력 724→1,028이다.
- 구역 밖 수정 · `game/src/logic/64-dim.js`의 주간 토벌 체력 보정에 고티어 계수를 추가해 후반 보스 패턴과 시전 차단을 위한 교전 시간을 확보했다. 필드 레이드도 바뀐 몬스터 능력치를 사용한다.
- `game/src/logic/02-jobs-stats.js`에서 주술암살자의 단검 공격력 7%를 보정했다. 기존 직업 검증에서 T40 단검 한 손의 사냥 속도가 단일 직업의 66%까지 내려간 경우를 보완했다.

## 보조 효과

- `66-charms.js`의 Lv.200 4칸 참 공격력은 +15~20이다. 보드 적용 한도는 공격력 +44, HP +160, 스킬별 피해 +6%, 회복 +8%다. 뿔참의 추가타는 14%, 렌즈참의 표식은 12%다.
- `11-rune-stock.js`, `52-rune-sets.js`에서 소켓 공격력 % 합계 +6%, 속성 추가 피해 +8%, 흡혈 +3%로 조정했다. 먹물가시의 대상 피해 증폭은 최대 +6%, 붉은모루의 최대 공격력 증가 +24%, 별의 궤도의 다음 스킬 피해 최대 +22%다. 푸른매듭 MP 절감은 18%다.
- `10-tables.js`, `13-element-data.js`, `40-characters-world.js`, `50-loot-combat.js`, `51-prefix.js`, `53-prefix-guard.js`에서 전설·유니크 접두사와 관련 합산 한도, 속성 보너스를 조정했다. 거인 사냥꾼 +20%, 질주의 기본 공격 간격 -12%다. 공유 피해 계수는 최대 ×1.36, 피해 흡수량은 한 번에 최대 HP의 14%, 회복량은 초당 최대 HP의 5%다.
- 맹렬한 일반 옵션의 등급 배율 적용 전 범위는 +3~6%다. 새 드롭과 명장의 숫돌 재굴림에 사용하고, 기존 저장 장비는 등급별 새 상한을 넘는 공격력 % 줄만 상한까지 내린다. 인챈트 스크롤은 이 빌드에서 별도 구현 대기 중이다.

## 검증

- 같은 레벨의 일반 검 장비로 24개 고정 시드 평타를 비교했다. 예상 처치 타수는 Lv.25 `5.35→5.36`, Lv.50 `5.60→5.73`, Lv.100 `15.59→15.12`, Lv.150 `14.26→13.75`, Lv.200 `21.48→21.84`다. Lv.100·장비 Lv.55는 약 45.5타로 동급 장비보다 느리다.
- 주간 토벌 4인 봇은 벨모라 3.7분, 모비화 3.2분에 클리어했다. 2인 기본 무기 파티는 두 토벌에서 실패했다. 사람 플레이는 미측정이다.
- 숲·해안·오아시스·단풍 필드 레이드에서 4인 봇을 두 시드씩 실행했다. 8회 모두 4.83~8.18분 사이에 전멸 없이 클리어했다.
- Antigravity `gemini-4-neon-low`로 보조 옵션 수치를 교차 검토했다. 최종 구현과 시뮬레이션은 Codex가 실행했다.
- `game/tests/`의 `itemlevel.mjs`, `loot.mjs`, `charms.mjs`, `prefix.mjs`, `prefix-util.mjs`, `rune-powers.mjs`를 갱신했다. `npm.cmd run build:logic`으로 생성 파일을 갱신했다.
- `npm.cmd run test:rules` 87/87, `npm.cmd run check:split`, `git diff --check` 통과.
