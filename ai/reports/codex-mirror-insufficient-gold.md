# 거울 이용료 부족 테스트

> - [ ] 거울(외형 변경)을 골드가 부족할 때 시도하면 거절되고 골드·외형이 그대로인지 확인하는 테스트를 `game/tests/looks.mjs`에 추가

`game/tests/looks.mjs`의 마을 거울 테스트에 이용료보다 1골드 부족한 상태에서 유효한 외형 변경을 요청하는 경우를 추가했다. 요청이 골드 부족 오류로 거절되고 골드와 기존 외형 배열이 그대로인지 확인한다.

`game`에서 `npm.cmd run test:rules`를 실행해 15개 테스트가 모두 통과했다. 메모리에서만 검증 조건을 바꿔 1골드가 부족해도 요청을 허용하자 새 거절 검사가 실패하는 것도 확인했다.

남은 작업은 통합 담당자의 검토와 작업 보드 갱신이다.
