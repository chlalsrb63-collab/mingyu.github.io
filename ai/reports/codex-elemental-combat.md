# 8대 피해 속성

작업 브랜치 `codex/elemental-combat`. 로컬 `main`의 장날 변경과 앞선 룬 소켓 및 룬 천공석을 포함합니다.

기존 전투에는 지팡이의 불·얼음·번개 반응, 개별 스킬의 출혈, 몬스터 특성의 화상·독·둔화가 있었습니다. 속성별 피해와 저항을 근접·원거리·스킬·몬스터 공격에 공통 적용했습니다. 물리 기본 피해에 스킬·몬스터의 주 속성과 장비 보너스를 합산하고, 방어력과 유형별 저항으로 경감합니다. 저항의 음수는 약점으로 작동하며, 장비 관통은 양수 저항을 0%까지 낮춥니다.

| 피해 유형 | 전투 효과 |
| --- | --- |
| 물리 | 치명타는 방어력 12%를 무시합니다. 방어구 파쇄 중에는 방어력이 추가로 10% 감소합니다. |
| 출혈 | 중첩되는 지속 피해. 실제로 걷거나 돌진하는 대상은 피해를 두 배 받습니다. |
| 화염 | 높은 직접 피해와 화상. 화상 동안 치유량 37% 감소. |
| 냉기 | 오한으로 이동·공격 둔화. 치명타 또는 오한 3중첩 시 빙결. 보스·수문장은 오한이 적용되며 빙결 면역. |
| 번개 | 편차가 큰 피해. 정해진 간격으로 짧게 경직시키고, 감전된 대상은 모든 피해를 10% 더 받습니다. |
| 독 | 공격력 8% 감소와 방어력 무시 지속 피해. 각 중첩은 만료 시점별로 합산하며 중첩 한도 없이 적용합니다. |
| 어둠 | 받는 속성 저항과 명중을 낮추는 저주. 어둠 피해의 일부를 체력으로 흡수합니다. |
| 빛 | 언데드·어둠 계열에 추가 피해. 실명, 신성 보호막 또는 회복. |

- 무기 보조 옵션에 속성 피해·관통·상태이상 옵션을, 방어구와 장신구에 개별·전체 저항을 추가했습니다. 신규 속성 옵션은 드롭과 재굴림에 적용되며, 이전 장비는 보유 옵션을 불러옵니다. 보스 고유 장비와 속성 접두사의 고유 보너스는 기존 장비에도 적용됩니다.
- 속성 룬 28종을 추가해 전체 룬은 116종입니다. 잿불꽃·은설호·폭풍항해·먹물가시는 화상·오한/빙결·감전·중독을 직접 사용합니다.
- 장날 룬 상인은 매 장날 3개로 발동하는 세트 한 종류와 희귀·전설 룬을 각각 하나씩 판매합니다. 기존 장날 구매 기록과 룬 도감 기록을 함께 불러오는 저장본을 확인했습니다.
- 몬스터·보물 상자 데이터 169종에 속성 프로필을 연결했습니다. 정예와 보스의 무작위 속성 강화는 표시 이름과 실제 공격에 함께 적용됩니다.
- 전투 피해는 유형별 색으로 분리했습니다. 최대 11종의 상태이상이 체력바 아래에 남은 시간과 중첩 수를 표시합니다. 장비·스킬 툴팁과 몬스터 도감에서 속성 정보도 확인할 수 있습니다.
- 사냥 검사는 속성 도입 직전 룬 빌드를 대조군으로 삼았습니다. 무기 7종과 성장 구간 4곳을 같은 시드 3개로 비교했고, 분당 처치 수는 대략 −7%에서 +9% 사이였습니다.
- 전체 규칙 71/71, 데이터·생성본·타입 검사 통과. 격리 로컬 서버에서 스킬 창의 속성 태그를 확인했고, 전투 상태 예시를 데스크톱과 휴대폰 크기의 브라우저에서 확인했습니다.

## 전직 전용기의 복합 속성과 물리 특화

- 단죄의 일격 물리·화염, 십자 난도 물리·출혈, 원소 비수 번개·어둠, 룬 먹화살 냉기·어둠. 전용기의 기존 직접 피해 일부를 각 속성으로 배분합니다. 십자 난도는 대검 휩쓸기에서 물리 피해, 후속 단검에서 물리와 출혈 피해를 줍니다. 단검 후속타 계수를 0.5에서 0.6으로 올려 사냥 속도를 보정했습니다.
- 화살비 25%, 파성추 35%, 철쇄 돌진 30%, 십자 난도 25%. 관통은 물리 피해의 방어력 차감에만 적용되고, 치명타·방어구 파쇄의 관통과는 남은 방어력에 각각 곱합니다. 속성 저항은 별도로 계산합니다.
- 전 무기 기본 공격의 기본 피해 유형은 물리입니다. 장비·룬이 더하는 속성 피해는 별도 집계됩니다. 무기·스킬(K)과 전직 상세에 속성 배지와 관통 수치를 표시합니다.
- 복합 전용기 4종을 실제 서버 행동으로 적중시켜 피해 유형을 검증했습니다. 최신 로컬 `main`에서 규칙 71/71 · 데이터 · 타입 · 생성본 검사 통과. 격리 서버의 전직 상세 7종에서 배지와 수치를 확인했습니다.
- 용기사 심연의 강림은 착지의 번개 충격파와 4초 어둠 장판을 순서대로 적용합니다. 착지로 피해를 준 적은 감전됩니다. 시전자는 장판으로 실제 깎은 HP의 30%를 회복하며, 장판에는 어둠 속성 자체의 흡혈을 더하지 않습니다.

## 버드나무 모험가 NPC

- 광장에 여울·산들·풀잎·이슬, 마을에 다온·마루·청솔·잔별을 추가했습니다. 주민 일정 시스템의 이동 경로에 따라 자기 무기를 들고 돌아다닙니다.
- 가까이 가면 한 차례 인사하고, F를 누르면 일상 대화를 이어갑니다. 격리 서버에서 광장의 여울과 마을의 다온을 만나 이동, 근접 말풍선과 F 대화를 확인했습니다.
