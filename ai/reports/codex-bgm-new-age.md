# BGM 뉴에이지 편곡

- 로컬 설정(O)에 배경음악 편곡을 추가했다. 기본값인 뉴에이지는 그랜드 피아노, 하프, 현악, 플루트를 중심으로 한다. 기존 편곡도 선택 가능하며 설정은 브라우저에 저장된다.
- 원래 멜로디와 화성을 공유한다. 타이틀은 94 BPM 피아노 아르페지오, 버드나무광장은 76 BPM 하프와 피아노, 버드나무 마을은 70 BPM 피아노와 플루트로 편곡했다. 던전은 저음 현악과 넓은 음 사이를 썼다. 보스·균열 전환과 밤 음악에 각 편곡이 적용된다.
- 편곡을 바꾸면 다음 음부터 같은 구간을 이어 듣는다. Web Audio 합성으로 게임 오디오를 재생한다.
- 자동 검사에서 24곡의 두 편곡 악보를 통과했다. 버드나무 마을 샘플은 뉴에이지 54.86초, 기존 51.89초다. 로컬 브라우저에서 설정 변경, 다시 접속, 식당 맵 전환을 확인했다. 설정 화면 캡처는 `game/shots/bgm-style.png`.
