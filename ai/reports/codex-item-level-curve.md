# 장비 성장과 전투 밸런스

- 작업 브랜치 `codex/item-level-curve`. 새 보스 패턴 24종이 포함된 로컬 `main` `4fbb31f`를 병합했다.
- 같은 장비 기본 공격력·방어력·HP·MP의 아이템 레벨 상승분은 Lv.30 +2.9%, Lv.70 +11.2%, Lv.110 +22.8%, Lv.150 +37%, Lv.190 +53.5%, Lv.200 +58%다. 강화·무기 숙련이 같은 기본 수치를 참조한다.
- 일반 옵션 굴림은 드롭·제작·숫돌에서 장비의 표시 아이템 레벨을 사용한다. 이미 저장된 일반 옵션은 다시 굴리지 않는다.
- Lv.200 4칸 참의 공격력은 +10~15다. 참 보드의 합산 공격력은 +30, 스킬별 피해 +8%, 회복 +10%까지 적용한다.
- Lv.200 룬의 일반 옵션은 기준치의 65%다. 소켓 전체에 전투 능력치별 합산 한도를 적용한다. 예를 들어 공격력 +32와 공격력 % +10%, 속성 피해는 속성별 +12%까지다. 세트 효과는 별도로 발동하며 피해 증폭, 재사용 초기화, 보호막 등 15종의 계수를 조정했다.
- 이전 빌드 대비 몬스터의 티어별 체력 증가 범위는 +8~48%, 공격력은 +5~36%다. 레이드 던전은 증가분 일부를 유효 체력에 반영하고 공격력에는 더 작은 비율을 적용한다. 주간 토벌에도 별도 계수를 사용한다.

## 측정

- 동일 등급·강화의 대검과 지팡이를 Lv.29~197에서 비교했다. 대표 필드 몬스터의 예상 처치 타격 수는 약 9~16% 늘었다. Lv.197 대검의 평균 타격 피해는 약 36% 늘었고, 같은 캐릭터가 받는 대표 몬스터의 타격 피해는 약 39% 늘었다.
- 고정 사냥장을 새 수치로 다시 측정했다. 경계에 걸린 복합 직업은 단일 직업과 같은 시드 5개 및 같은 사냥 시간으로 재검사한다.
- Chromium에서 기본 능력치와 장착 레벨이 서버 수치와 일치하고, 장비 비교가 룬의 합산 한도만큼만 계산되는 것을 확인했다.
- 2~4인 레이드 봇 검증과 새 보스 패턴 검증을 통과했다. 주간 토벌의 장비를 갖춘 4인 봇은 벨모라 3.4분, 모비화 3.2분에 클리어했다. 장비가 부족한 2인은 두 보스에서 모두 실패했다.
- 최신 보스 패턴 병합본에서 `npm run test:rules` 87/87 통과. `npm run check:split`, `node --check public/items.js`, `git diff --check` 통과.

## 후속 · 아이템 레벨 보정 증가폭 4배

- 기본 능력치의 아이템 레벨 증가분을 4배로 키웠다. 최대 보정은 +58% → +232%다. 강화 전 Lv.1 철제 대검은 공격력 6이고, 운철 참마도는 Lv.181 269 → Lv.200 299다. 같은 운철 참마도의 이전 차이는 135 → 142였다.
- `game/src/logic/10-tables.js`에서 같은 성장 구간의 필드 압력을 몬스터 티어 기준으로 조정했다. 대검·지팡이 표본(Lv.29~197)의 동급 필드 몬스터 예상 처치 타격 수는 직전 빌드 대비 약 2% 이내였다.
- 구역 밖 수정 · `game/src/logic/64-dim.js`의 레이드 공격력과 소규모 파티 체력 계수를 조정했다. 후반 2~3인 고정 표본 4회가 모두 클리어했다.
- `game/tests/itemlevel.mjs`에서 보정 상한과 같은 장비의 교체 수치를 확인한다. `game/tests/bosses2.mjs`에서 강화된 필드 보스의 체력과 패턴을 검증한다. `game/src/logic.js`를 빌드 명령으로 재생성했다.
- Chromium에서 같은 운철 참마도의 Lv.181 → 200 장비 비교가 공격력 +30을 표시하는 것을 확인했다.
- 최종 `npm run test:rules` 87/87 통과. `npm run check:split`과 `git diff --check`도 통과했다.
