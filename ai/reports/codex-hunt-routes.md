# 레벨대별 사냥 동선과 성에왕의 성채

- 바람초원은 쌍두 토끼 → 개구리 → 까마귀 → 양 순서로 깊어진다. 가장 먼 사냥터에 Lv.25 금 간 뿔 숫양을 추가하고 속삭임 숲 입구의 Lv.29 반쪽 멧돼지 비중을 늘렸다.
- 지하묘지 깊은 회랑에서 네온 시티로, 하수도 끝에서 수정 동굴로 이어지는 편도 출구를 추가했다. 출발지의 기존 수호자는 유지하고 도착지는 몬스터가 자리를 잡지 않는 구역으로 둔다. 마을과 숲에서 가는 기존 출입구도 이용할 수 있다.
- Claude의 해안 순환로는 네온 시티 → 정글 해안도로 Lv.77–101 → 산호 해안 Lv.101–125 → 모래바람 오아시스 Lv.109–133으로 이어진다. 산호 해안 몬스터와 상자 보상을 조정했다. 오아시스에서 수정 동굴로 돌아갈 수 있다.
- 단풍 왕도에 Lv.185 뿌리짐승, Lv.193 올빼미, Lv.197 왕릉 파수꾼을 차례로 배치했다. 기존 메인 의뢰 뒤에 세 구간의 의뢰와 성채 보스 의뢰를 붙였다. Lv.181 이후 세 의뢰의 기본 보상 합계는 약 1,748만 XP다.
- 왕도 남동쪽의 성에왕의 성채는 캐릭터 Lv.200부터 이용한다. 입구 야영지, 연결된 두 순환로, 이동의 돌 세 곳과 안쪽 왕좌가 있다. 외곽의 서리창 쌍두토끼, 안쪽의 갈라진 유리날개와 성에왕 유리뿔에 서로 다른 코드 픽셀 모델을 적용했다. 성채 몬스터는 일반 차원 균열에서 사용하지 않는다.
- 출입 검사는 포털, 파티원, 이동의 돌, 스탯 초기화, 저장·재접속에서도 적용한다. 월드맵에도 Lv.200 전용으로 표시한다.
- 지도 및 규칙 검증에서 네 개의 편도 문 경고가 나왔다. 두 구간에서 각 두 칸을 공유하는 의도된 출구다. 기본 Lv.200 장비로 여섯 무기를 돌린 평지 전투 시뮬레이션에서 일반몹 중앙 처치 시간은 4.9~9.4초였다. 기본 회피와 재합류를 허용한 4인 시뮬레이션에서 보스는 약 170초였다. 실제 파티의 소모품 사용, 전체 동선, 골드·장비 보상은 추가 플레이 테스트에서 비교한다.
