# Alpha 1.0.1 월드 원근·광원과 LAN

- 기존 쿼터뷰에 먼 지형과 나무의 색 대비를 낮추는 공기 원근, 해 높이와 방향에 따른 나무·건물 그림자, 나뭇잎 사이의 햇빛, 등불·수정이 바닥에 비추는 빛을 추가했다.
- 타일 좌표, 캐릭터 크기와 정렬, 가림 시 캐릭터 실루엣, 조준과 클릭 계산을 유지했다. 지형 효과는 공격 전조 아래에 그린다. 전경·배경 처리는 일부 환경 스프라이트에만 적용된다.
- 설정 → 원근감·광원에서 켜고 끌 수 있다. 기본은 켜짐이고 브라우저에 저장된다.
- LAN IP가 인증이나 채널 소켓을 온라인 서버로 돌리던 경로를 수정했다. HTTP API와 WebSocket은 같은 서버 주소를 사용한다. 외부 미러는 기존 온라인 경로를 사용한다.
- 대상은 기존 8830 LAN 서버와 저장 공간이다. 본인은 `http://localhost:8830`, 같은 와이파이의 동료는 `http://192.168.31.58:8830`. 각자 계정으로 같은 서버·채널을 선택한다.
- 저장 공간을 분리한 검증 서버에서 두 브라우저가 루프백과 LAN IP로 각각 입장해 1서버 채널 1에서 서로 보이고 파티를 맺었다. 옵션 ON/OFF 저장과 동일한 좌표 투영도 확인했다.
- 비교 화면은 `game/shots/scene-depth-town-off.png`, `game/shots/scene-depth-town-on.png`. 야간 광장과 숲 검수는 `game/shots/scene-depth-town-night.png`, `game/shots/scene-depth-forest.png`.
- 전체 검사 57/58. 정글 생성 시간 검사가 첫 실행에서 174ms로 한도를 넘었고, 단독 재검사에서 82ms로 통과했다. `accounts`, `check:split`, `data:check`, `typecheck`, 변경 JS 구문 검사 통과.
