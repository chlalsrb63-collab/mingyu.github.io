# 캐릭터 스킬 이펙트 개선

- 물리, 출혈, 화염, 냉기, 번개, 독, 어둠, 빛 적중마다 다른 픽셀 모양과 잔상을 사용합니다. 복합 피해에서 비중이 24% 이상인 비물리 속성 중 가장 큰 값을 표시합니다. 같은 대상에 75ms 이내 연속으로 들어온 적중 섬광은 한 번만 그립니다.
- 처형 내려베기, 급소 터뜨리기, 갈고리 창, 점화 폭발, 영혼 착취, 저격에 시전 또는 적중 연출을 보강했습니다. 곡사 폭약 화살의 포물선과 불씨를 추가했습니다.
- 메테오 스톰, 뇌룡승천, 심연의 계약, 메아리 법진, 혈흔 폭발, 빙결창은 실제 타격 지점에 전용 파편을 그립니다. 뇌룡승천은 마지막 타격에 번개 갈래가 더 많이 보입니다.
- 정해진 팔레트의 그림을 캐시하며, 먼 거리와 여러 효과가 겹치는 상황에는 추가 이펙트를 제한합니다. 기존 공격 판정, 피해량, 쿨타임을 사용합니다.

## 검증

- `node scripts/test-all.mjs --no-build skills combos` 통과. 변경 JavaScript 파일 구문 및 `git diff --check` 확인.
- Chromium에서 8개 속성의 타격과 소멸 프레임, 전직 대표기 6종의 적중과 잔상 프레임을 확인했습니다.
- 별도 로컬 서버에 테스트 계정으로 접속했습니다. 브라우저에서 냉기 연속 피격과 처형 내려베기, 저격, 메테오 스톰, 점화 폭발 이벤트를 재현해 이펙트가 등록되고 표시되는 것을 확인했습니다.
