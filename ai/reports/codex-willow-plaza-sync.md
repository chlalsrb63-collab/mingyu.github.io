# 버드나무광장 로컬 통합

GitHub의 `main`과 Claude 브랜치가 가리키는 `8057ed9`를 로컬 플레이 빌드의 기준으로 삼았다. 실행 주소는 `http://127.0.0.1:8865/`다.

| 영역 | 이번 반영 |
| --- | --- |
| 광장 | 표시명은 버드나무광장. 회관·수련관 표지, 귀환, 버드나무 마을 대사와 퀘스트를 맞췄다. 지도 ID는 `town`이다. |
| 전투 | 대검의 두 횡베기가 교대한다. 피해 보정은 기존 세 공격 주기로 계산한다. 여섯 무기군에서 화면상 원근과 팽창에 따른 크기 변화를 제거하고 검기·활시위 동작을 유지했다. 현행 단검의 표적 없는 기습 신호 19번을 남기고 이전 스킬 효과를 정리했다. |
| 외형 | 전설 실루엣 27종을 적용했다. 전설 활 4종도 기존의 시위·화살 애니메이션을 쓴다. 검수용 AI 아이콘의 설치 상태는 바꾸지 않았다. |
| 소리 | 기존 단풍 왕도·차원 균열·실내·야간 상태를 유지하며 타이틀·필드·던전·작업장의 원곡을 연결했다. 합성기 24곡이며, 에디터도 같은 곡 목록을 참조한다. |
| 의뢰 | 서비스를 제공하는 NPC에게도 대화와 의뢰를 열 수 있다. 마을 편집기 검증을 막던 모듈 내보내기 충돌을 고쳤다. |

## 확인

- `npm run build:logic`, `npm run data:check`, `npm run test:rules` 29/29, `npm run typecheck`, `npm run check:split`.
- 브라우저 실게임에서 지도 13곳의 음악과 쥬쥬식당 곡의 256스텝 반복 확인. 주요 18곡은 Web Audio로 두 바퀴 렌더했다.
- 전설 스프라이트·아이콘 342개 내보내기 완료. 확인 이미지 `game/shots/willow-plaza.png`, `game/shots/sword-no-resize.png`, `game/shots/legendary-silhouettes.png`.
