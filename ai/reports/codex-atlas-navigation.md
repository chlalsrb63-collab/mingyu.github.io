# 버드나무마을 생활 의뢰와 루넬샤대륙 지도

클로드의 70×56 마을 확장은 `e4500d1`로 로컬 `main`에 들어왔다. 첫 생활 의뢰 4종을 일일 게시판에 추가했다. 요리는 숙련도 5부터 열리고 네 의뢰 모두 기존 알바와 하루 4회 한도를 공유한다.

| 의뢰 | 검증한 경로 | 시간 | 지급 | 재료비 | 순익 |
| --- | --- | ---: | ---: | ---: | ---: |
| 젖은 마룻널 말리기 | 게시판 → 버들의 수리대 | 2.3초 | 540G | 72G | +468G |
| 갈대의 아침 바구니 | 게시판 → 연못에서 직접 낚시 → 공동 부엌 | 58.7초 | 168G | 60G | +108G |
| 등교길 주먹밥 | 게시판 → 공동 부엌에서 직접 조리 → 촌장 버들 | 97.3초 | 600G | 162G | +438G |
| 솔의 공연 통지 | 게시판 → 솔에게 통지서 수령 → 봄이 | 48.9초 | 126G | 0G | +126G |

- 서버가 실제로 받아들인 이동과, 낚시·조리·수령·납품을 실행한 표본이다. 시간은 수락부터 완료까지다. 마른 가지와 들꽃잎은 보유분 상점 매각가, 조리 부재료는 상점가로 비용을 매겼다. 별도 채집·장보기 및 다음 의뢰를 위한 게시판 복귀 시간은 빠져 있다. 조리 퍼즐은 판당 12초로 가정했다.
- 등급, 긴급 및 배달 팁에 따라 보수가 달라진다. 쉬움·보너스 없음 기준 순익은 표 순서로 108G, 84G, 약 155G, 96G다. 통지서는 봄이 한 명에게 전하는 기존 소포 운송 규칙을 사용한다.
- 바람초원 첫 이동의 돌에서 기본공격으로 60초씩 사냥한 대검 캐릭터의 직접 획득 골드는 Lv.1 37G, Lv.8 61G(상자 1개), Lv.17 45G였다. 별도로 획득품을 실제 상점에서 팔면 각각 총 109G, 319G, 286G였다. 사냥터 진입과 상점 왕복은 계측에서 제외했다. 현장 낚시와 무재료 배달의 표본은 약 110G/분과 155G/분으로, 드롭 편차 없이 보수를 받는 일일 수입원으로 쓸 만하다. 이 표본에서 장비 매각을 포함한 사냥 수익은 드롭에 따라 더 높았다.

## 지도

- M → 세계의 건물 패널을 제거하고, 건물 안에서는 소속 마을에 현재 위치·파티원·의뢰를 표시한다. 세계 지도는 기존 아이콘과 관문 경로를 유지하면서 대륙의 해안·수심·산맥·강줄기·사막을 픽셀 아트로 보강했다.
- M → 지역의 건물 목록이나 문 아이콘을 누르면 서버가 내려준 실제 문 타일까지 걷는다. 로컬 브라우저에서 루루 의상실을 선택해 문을 통과했고, 건물 안에서 바람초원 세계 경로도 확인했다.
- 지도 파일은 `worldmap*.js`, `radar.js`, `input.js`와 지도 창 연결부다. 의뢰는 `12-life-tables.js`와 `58-life.js`, 게시판·시설 안내는 `board.js`, `actions.js`, `station.js`다.
- 확인 이미지 `game/shots/atlas-lunelsha.png`, `game/shots/atlas-local-mobile.png`, `game/shots/atlas-building-arrival.png`. 데스크톱과 휴대폰 세로에서 페이지 오류 없이 확인했다.
- `npm run test:rules` 49/49, `npm run data:check`, `npm run typecheck`, `npm run check:split` 통과. 기본 의뢰 수락과 완료, 숙련도 해금, 재료 차감, 중복 지급 방지, 공유 일일 한도를 검증했다. 실제 브라우저에서 게시판을 열고 공연 통지 의뢰를 수락했으며, 공동 부엌과 수리대에서 시설명이 표시됐다.
