# 단검·창 연출과 무기 자세

- 암습(84)은 착지한 곳의 교차 칼자국, 그림자 칼날(85)은 실제 진행 경로의 세 단검, 나선 찌르기(87)는 전방의 두 나선, 유성창(88)은 진행 방향으로 뻗는 충격으로 구분했다. 전용 연출 뒤에 겹치던 기본 잔상은 해당 스킬에서만 생략했다.
- 단검 역수 베기, 창의 준비·내뻗기, 스태프의 들어 올리기·내지르기, 마도서의 방향별 전방 시전을 보강했다. 무기 픽셀 크기와 기존 적중 시점은 유지했다.
- 단검과 창에서 휘두르는 소리와 명중음을 분리했다. 일반·마무리·치명타·스친 타격은 한 가지 소리를 재생한다. 해머 착지음은 기존 전용 경로를 쓴다.
- 문법 검사와 브라우저 프레임 확인. 오프라인 Web Audio 8변주에서 새 명중음의 최대 피크는 단검 0.215, 창 0.292였다. 클리핑 없이 음소거와 같은 프레임 반복 제한이 작동했다.
