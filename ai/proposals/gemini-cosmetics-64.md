# 작은꼬리 64×64 외형 장비 2세트 설계·좌표·착용 명세 (`gemini-cosmetics-64`)

## 0. 현재 작업 트리 렌더러 점검 결과 및 좌표계 규약

1. **현재 브랜치(`gemini/work`) 렌더러 상태 확인**:
   - `game/public/sprites.js`: `export const SIZE = 32; const S = 32, BIG = 64;` — 현재 작업 트리는 64×64 내부 캔버스(`BIG`)에 그린 뒤 `half()`로 축소하여 **32×32 프레임**을 반환함.
   - `game/public/wardrobe.js`: `const SZ = 32;` 및 `brush.r()` 내부 `Math.round(x)` — 현재 32×32 정수 좌표만 받으며 0.5 논리 좌표를 아직 받지 않음.
   - 지침에 따라 다른 에이전트가 진행 중인 64×64 캐릭터·NPC 리뉴얼을 덮어쓰지 않도록 `sprites.js`·`wardrobe.js`·`game/src/logic/`은 수정하지 않고, **0.5 논리 좌표(`32` 기준, `0.5 = 64×64 네이티브 1px`) 호환 코드**와 **64×64 네이티브 투명 레이어 시안(`asset/generated/cosmetics-64/`)**, **착용 검증 프리뷰 시트 2장(`game/shots/gemini-cosmetics-64-*.png`)**으로 준비했다.
2. **좌표계 변환 규약 (32 논리 좌표 ↔ 64 네이티브 픽셀)**:
   - 월드 캐릭터 크기·발 기준점(`FOOT = [16, 29]` 논리 = `[32, 58]` 64px)·중심축(`A.cx = 15.5` 논리 = `31.5` 64px)·머리 흔들림(`HEAD_BOB`)은 기존과 동일하다.
   - 논리 좌표 `1.0` = 64×64 캔버스 `2px`, 논리 좌표 `0.5` = 64×64 캔버스 **정확히 `1px` (새 도트 한 칸)**.
   - 큰 실루엣(크라운·몸통·망토 외형)은 `1.0` 단위(2px 블록)로 먼저 잡아 1배율 가독성을 유지하고, **챙 모서리 단차·누빔 솔기·황동 버클·렌즈 바깥 1도트 반짝임**만 `0.5` 단위(64 네이티브 1px)로 세밀하게 다듬는다.
3. **필수 레이어·가림 규칙**:
   - **레이어 순서 (`dress`)**:
     - `front` / `side`: `등(BACK)` → `몸(base)` → `상의(TOP)` → `어깨끈/버클(BACK_FRONT)` → `모자 크라운(HAT.draw)` → `귀·뿔·개구리 눈혹 복원(ears)` → `모자 앞챙/장식(HAT.over)` → `눈 복원(guardEyes)` → `얼굴 장식(FACE.draw)` → `눈 재복원(guardEyes, covers: false)`.
     - `back`: `몸(base)` → `상의(TOP)` → `등(BACK, y >= A.bt 영역만 유지하여 머리 아래로 들어감)` → `모자(HAT)`.
   - **종족별 귀·뿔·개구리 돌출눈 보호**:
     - 두 세트의 모자 2종 모두 `ears: "through"`, `bumps: true`로 설정하여 토끼(`tall`), 사슴(`antler`), 뿔(`horn`), 고양이/여우 귀가 크라운 위로 자연스럽게 나오며, 개구리(`sp=7`, `bumps: true`, `ey=17`)의 돌출눈 혹이 모자 크라운 양옆 위로 항상 노출된다.
     - 얼굴 안경/물안경 2종 모두 `covers: false`로 설정하고 눈동자 픽셀(`EYE_PIX`) 바깥 0.5단위(1도트)에만 림을 배치해 눈동자를 절대 가리지 않는다.

## 2. 품목별 앞(Front) · 옆(Side) · 뒤(Back) 64도트(0.5 논리 좌표) 구조 명세

### 2-1. 등불 나루 구조대 (`ferry` 세트)
1. **`hat_ferry_souwester` (물막이 챙모자)**
   - **정면(`front`)**: 크라운은 `y = T - 2.0 .. T - 0.5`, 폭 `W - 1`의 낮은 사다리꼴 청록 방수모(`#24666e`)이며 좌상단 하이라이트(`#458e96`)와 정중앙 주황 신호 패치(`w = 2.0, h = 1.0`, `#f06828` + 상단 `#ffa24a` 0.5줄)가 들어간다. 챙은 `y = T - 0.5`(윗챙 `#458e96`, 폭 `W + 2`)와 `y = T`(아랫챙 `#16424a`, 폭 `W + 3`, 양 끝 `+0.5` 하강 단차)의 **낮은 이중 챙**으로 구성된다. 양 볼 외곽(`A.x0`, `A.x1`)을 따라 `y = T + 0.5 .. T + 1.5`에 0.5폭의 짧은 턱끈(`#16424a`)과 끝단 황동 스냅(`#d8aa48`) 1도트가 찍힌다.
   - **측면(`side`)**: 앞쪽(`A.x1` 방향)으로 `+1.5` 나온 짧은 이중 처마 챙과 뒤쪽(`A.x0` 방향)으로 `-2.0` 뻗어 `y = T + 1.0`까지 비스듬히 내려오는 물받이 뒷챙(사우스웨스터 실루엣)이 특징이다. 볼 중앙(`c0 - 0.5`)에 짧은 턱끈과 황동 스냅 1도트가 보인다.
   - **후면(`back`)**: 목덜미(`y = T + 0.5 .. T + 1.0`, 폭 `W + 3`)를 넓게 덮는 이중 방수 뒷챙과 중앙 세로 방수 솔기(`0.5` 폭 `#16424a`), 뒷챙 정중앙의 주황 반사 탭(`1.0 × 0.5`, `#f06828`)이 보인다.
2. **`top_ferry_oilskin` (등불지기 방수복)**
   - **정면(`front`)**: 상단(`bt`)에 짧은 청록 겹깃(`#458e96`/`#24666e`)이 좌우로 열리고, 정중앙(`x = 15.5..16.5, y = bt + 1.0`)에 `1.0 × 1.0`(64기준 `2×2` 도트) 황동 매듭(`#d8aa48` + 좌상단 `#fff0a8` 1도트)이 놓인다. 양어깨(`x = 13.0, 18.0`)에서 시작해 옆구리 밑단(`x = 12.5, 18.5, y = foot - 0.5`)까지 내려오는 굵은 주황 구조끈(`#f06828`)과 0.5단위 세로 앞섶 솔기가 선명하게 읽힌다.
   - **측면(`side`)**: 앞가슴의 황동 매듭 옆면과 어깨에서 옆구리(`x = 15.0..16.0`)로 수직 하강하는 주황 구조끈, 옆구리 황동 D링 1도트가 보인다.
   - **후면(`back`)**: 등판 위에서 X자로 교차해 양 옆구리로 내려가는 주황 구조끈(`#f06828`/`#a83c14`)과 등 중앙 황동 연결 고리(`#d8aa48`)가 보인다.
3. **`back_ferry_halfcape` (조난등 반망토)**
   - **정면(`front`)**: `BACK_FRONT`가 오른쪽 어깨(`x = 13.0, y = bt`)의 2×2 황동 고정 버클(`#d8aa48`)과 가슴을 가로지르는 어두운 청록 고정끈을 그리고, `BACK`이 한쪽 어깨(`x = 10.0 .. 13.5, y = bt .. foot - 0.5`) 뒤로 비대칭 반망토 실루엣과 세로 주황 신호선 1줄을 노출한다.
   - **측면(`side`)**: 등 뒤(`x = 9.0 .. 13.5`)로 비스듬히 흘러내리는 청록 반망토 위에 세로로 길게 붙은 주황·은백 반사 띠(`#f06828` + `#d8f4f0`)와 비에 젖어 짙어진 톱니형 아랫단(`#0e2b33`)이 보행(`sway`)에 맞춰 흔들린다.
   - **후면(`back`)**: 전체 등을 다 덮지 않고 왼쪽 반쪽(`x = 11.0 .. 16.5`)만 덮는 비대칭 반망토 형태다. 세로로 길게 내려오는 2열 반사 띠(`#d8f4f0` 0.5줄 + `#f06828` 1.0줄)와 비에 젖어 무겁게 가라앉은 어두운 청록 아랫단(`#0e2b33`, 0.5단위 물방울 단차)이 또렷하다.
4. **`face_ferry_goggles` (황동 물안경)**
   - **정면(`front`)**: 눈동자(`A.lx, A.rx, y = A.eye`)는 전혀 건드리지 않고, 각 눈의 아래(`y = eye + 1.0`)와 위(`y = eye - 1.0`)에 0.5단위(1도트) 두께의 얇은 청록 렌즈 가장자리(`#458e96`, 좌상단 1도트 `#d8f4f0`)만 두른다. 양쪽 바깥 관자놀이(`x = A.lx - 1.5`, `x = A.rx + 1.5, y = eye - 0.5 .. eye + 1.0`)에 호박색·황동 옆테 브래킷(`#ffa24a`/`#d8aa48`)을 배치하고 코 위 브리지(`y = eye`)를 황동 1도트로 잇는다.
   - **측면(`side`)**: 앞쪽 눈과 바깥 눈의 청록 렌즈 가장자리, 그리고 뒤쪽 머리 옆선(`16 - A.halfAt(eye)`)까지 이어지는 호박색·황동 옆테와 갈색 스트랩이 보인다.
   - **후면(`back`)**: 머리 양옆 끝(`A.x0, A.x1, y = A.eye`)에 황동 옆테 스트랩 끝점 1도트씩만 표시된다.

5. **`hat_snow_earflap` (별바늘 귀덮개모)**
   - **정면(`front`)**: 뿔처럼 보이지 않도록 크라운 상단(`y = T - 2.0 .. T - 0.5`, 폭 `W`)을 평평하고 완만한 미색 누빔(`#f2ead8`, 0.5단위 세로 누빔 골 `#c8bca4`)으로 잡고, 이마 정면(`y = T - 1.0 ..    - **측면(`side`)**: 낮은 미색 누빔 크라운과 앞이마 자주색 양모 패드, 그리고 볼 옆(`x = c0 - 1.5 .. c0 + 0.5, y = T .. T + 2.5`)을 덮는 각진 방한 귀덮개와 금빛 별단추 1점이 보인다.

   - **정면(`front`)**: 목 아래 V자로 포개진 미색 겹섶(`#fffdf4`/`#f2ead8`) 위로 자줏빛 양모 가슴끈(`#7a3058`, 높이 1.0)이 가로지르며 왼쪽 가슴에 별금속 핀(`#f4d068`) 1도트가 빛난다. 몸통 전체에는 왼쪽 위에서 오른쪽 아래(`↘`) 한 방향으로 이어지는 **굵은 대각선 누빔 솔기(`#c8bca4`/`#968870`)**가 0.5단위 계단으로 흐른다.

7. **`back_snow_surveycape` (눈바람 측량 망토)**
   - **정면(`front`)**: `BACK_FRONT`가 목 둘레의 자줏빛 양모 칼라(`#7a3058`)와 정중앙 별금속 버클(`#f4d068`)을 그리고, `BACK`이 양옆 어깨 아래(`x = 10.5..12.5`, `19.0..21.0`)로 갈라진 자줏빛 망토 두 폭의 외곽과 오른쪽 허리 옆의 미색 삼각 지도 주머니 끝단을 살짝 보여준다.
