# game/assets — 외부 무료 에셋 보관함

인터넷에서 받은 무료 에셋(도트 스프라이트, 타일, UI, 폰트, 효과음, 음악)을 **원본 그대로** 넣어 두는 곳입니다.
이 폴더는 배포되지 않습니다. 게임이 실제로 쓰는 파일만 골라 `game/public/assets/`로 옮겨야 화면에 나옵니다.

## 1. 넣기 (사람)

| 폴더 | 무엇을 |
| --- | --- |
| `incoming/` | 아직 분류 안 한 것 전부 (압축은 풀어서, 팩 이름 폴더째로) |
| `sprites/` | 캐릭터 · 몬스터 · 이펙트 스프라이트 시트 |
| `tiles/` | 지형 타일 · 소품 |
| `ui/` | 창 테두리 · 버튼 · 아이콘 |
| `fonts/` | 폰트 (라이선스 파일 같이) |
| `sfx/` | 효과음 |
| `music/` | 배경 음악 |

그리고 **반드시** `CREDITS.md`에 팩마다 한 줄을 적습니다: 이름 · 만든 사람 · 받은 주소 · 라이선스.

- **CC0 / 퍼블릭 도메인**이 가장 좋습니다 (표기 의무 없음).
- **CC-BY**는 써도 되지만 게임 안(설정 › 만든 사람들 등)에 크레딧을 보여야 합니다.
- **비상업(NC) · 재배포 금지 · 라이선스 불명확**한 것은 공개 게임에 쓰지 않습니다. 넣지도 마세요.
- 원본 라이선스 파일(LICENSE.txt 등)도 같이 넣어 둡니다.

## 2. 고르고 연결하기 (AI에게 맡기기)

AI에게 예: "`game/assets/incoming/<팩>`에서 숲 몬스터에 쓸 만한 것을 골라 연결해 줘" 라고 하면, AI는:

1. 실제로 쓸 파일만 `game/public/assets/<종류>/`로 복사합니다 (원본은 여기 그대로).
2. 형식을 맞춥니다: 이미지는 **PNG**, 소리는 **OGG**(또는 MP3).
3. 도트 크기를 게임에 맞춥니다: 캐릭터는 **16×16** (32×32 시트 안), 바닥 타일은 **32×16 쿼터뷰 마름모**.
   크기가 다르면 정수배로만 늘리거나 줄이고, 흐리게(보간) 만들지 않습니다.
4. `game/public/assets/manifest.json`에 키로 등록하고 (`"mob.twinhare"`, `"sfx.coin"` …),
   `game/public/assetlib.js`의 `Assets.canvas(key) || 코드로_그린_것()` 방식으로 연결합니다 —
   파일이 없으면 지금처럼 코드 그림이 그대로 나옵니다.
5. `CREDITS.md`의 해당 줄에 "사용 중: 어디에" 를 채우고, CC-BY면 게임 안 크레딧도 추가합니다.

자세한 규칙은 저장소 맨 위 `AGENTS.md`의 "External assets" 절을 보세요.
