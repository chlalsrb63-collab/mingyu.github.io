# 테일즈테일즈 (Tales Tales)

> 「꼬리의 이야기」 — 꼬리 달린 작은 동물 친구들의 쿼터뷰 파티 RPG

판타지 세계와 현대 도시가 한 광장에 겹쳐 버린 멀티버스 파티 헌팅 RPG입니다. 테일즈위버 · 어둠의전설처럼
작은 동물 모험가(고양이·여우·곰)가 자기 몸만 한 무기를 직접 휘두르는 탑다운 도트 화면에
디아블로식 파밍, 룬, 그리고 "경험치로 능력치를 사는" 끝없는 성장을 얹었습니다.

- **플레이**: https://lumentale-online.higgsfield.app (배포 대기 중)
- 그림 · 소리는 전부 코드로 생성합니다 (이미지/오디오 파일 없음).

## 구조

```
src/logic.js    게임 규칙 전부: 아이템·몬스터·스킬 표, 맵 4개, 전투·드랍·의뢰·강화 시뮬레이션
src/room.ts     채널 하나 = Durable Object 하나. 소켓과 시계(초당 10틱)를 맡고 캐릭터를 저장
src/worker.ts   /ws/<채널> 웹소켓을 해당 채널로, /api/*(가입·로그인·로그아웃·내 캐릭터·서버 목록)를 저장소로 연결
src/accounts.js 아이디·비밀번호(PBKDF2)·세션 토큰·로그인 제한, 1서버(s1-ch1·s1-ch2)·2서버(s2-ch1·s2-ch2), 서버별 캐릭터 키(아이디@s1)
public/         브라우저: client.js(입력·UI·이름표), scene2d.js(탑다운 도트 지형·소품·이펙트·무기 휘두르기), sprites.js(32px 동물 캐릭터·무기·몬스터), species.js(동물 종류·얼굴 부위), looks.js(외형 고르기·거울), art.js(아이콘·미니맵), audio.js(칩튠 합성)
public/growth.js 스킬 수련 · 창고 · 펫 · 주문서 · 부활 깃털 · 아이템 필터 · 자동 물약의 화면 쪽
tests/          규칙 테스트 (node tests/sim.mjs · party.mjs · loot.mjs · life.mjs · world.mjs · hard.mjs · content.mjs · growth.mjs)
```

서버가 모든 판정을 합니다. 브라우저는 "이동/공격/구매" 같은 의도만 보내고, 서버는 위치·쿨타임·
골드·NPC와의 거리까지 검사한 뒤 초당 10번 각 플레이어에게 자기 주변 상황만 보내 줍니다.
캐릭터는 채널과 무관한 저장소에 보관되므로 어느 채널로 들어가도 같은 캐릭터입니다.

## 밸런스

레벨 곡선 · 몬스터 · 물약 · 골드는 헤드리스 봇으로 맞췄습니다: 직업마다 평범한 장비의 캐릭터가 Lv.1부터
자기 레벨에 맞는 사냥터에서 자동 사냥하며, 주운 장비를 입고 · 남는 것은 팔고 · 번 돈으로 물약과 스킬
수련을 삽니다(마을 왕복 45초, 사망 50초 손실로 계산). 목표는 Lv.7까지 약 15분, 뒤로 갈수록 대역마다
조금씩 길게, Lv.40까지 10~12시간이고, 혼자서 입구 사냥터에서는 거의 죽지 않되 깊은 곳에서는 가끔 죽는 정도.
필요 경험치는 예전 곡선에 레벨과 함께 커지는 배수(Lv.7까지 ×6 → Lv.40 ×82)를 곱하고, 의뢰 경험치도 같은 배수로
올렸습니다. 깊은 몬스터일수록 골드가 덜 나오고(Lv.36 이후 ×0.3), 장비 판매가는 정가의 5%, 일반 몬스터의 장비
드랍은 줄이고(정예 35%), Lv.26부터 쓰는 농축 물약(HP 480+24%, MP 340)을 더했습니다. 피의 심연 몬스터의
공격력은 약 20% 낮췄습니다(전에는 평범한 장비의 Lv.32가 입구에서 2분에 9~34번 쓰러졌음).
