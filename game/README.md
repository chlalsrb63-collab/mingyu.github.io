# 루멘테일 온라인 (Lumentale Online)

판타지 세계와 현대 도시가 한 광장에 겹쳐 버린 멀티버스 파티 헌팅 RPG입니다. 테일즈위버 · 어둠의전설처럼
대각선으로 걷는 쿼터뷰(2:1 아이소메트릭) 도트 화면에
디아블로식 파밍, 룬, 그리고 "경험치로 능력치를 사는" 끝없는 성장을 얹었습니다.

- **플레이**: https://lumentale-online.higgsfield.app (배포 대기 중)
- 그림 · 소리는 전부 코드로 생성합니다 (이미지/오디오 파일 없음).

## 게임 내용

| | |
| --- | --- |
| 직업 | 전사(양손검) · 도적(단검) · 레인저(총) · 마도사(지팡이), 직업별 스킬 3개 |
| 세계 | 넥서스 광장 → 동쪽 판타지(바람초원 · 속삭임 숲 · 수정 동굴) / 서쪽 현대(네온 시티) |
| 파밍 | 일반 · 마법 · 희귀 · 전설 등급, 무작위 옵션 11종, 홈(소켓), 강화 +10 |
| 룬 | 룬 9종을 홈에 끼우고, 정해진 순서로 채우면 룬어 6종 완성 |
| 성장 | 레벨 50 + 수련: 경험치를 바쳐 힘 · 체력 · 지력 · 수호를 한계 없이 올림 |
| 파티 | 최대 4인. 경험치 · 의뢰 처치 · 전리품(개인별 굴림)을 공유, 인원이 많을수록 총 경험치 증가 |
| 사냥 | 정예 몬스터(금빛 테두리), 파티 전원을 노리는 보스 패턴, 자동사냥 |
| 시점 | 쿼터뷰. 방향키는 화면의 대각선 네 방향, 땅을 클릭/터치하면 길을 찾아 걸어감 |
| 조작 | 방향키/WASD · 클릭 이동 · Space 공격 · 1 2 3 스킬 · Q/E 물약 · F 대화 · R 자동사냥 · P 파티 · 모바일 터치 |

## 구조

```
src/logic.js    게임 규칙 전부: 아이템·몬스터·스킬 표, 맵 4개, 전투·드랍·의뢰·강화 시뮬레이션
src/room.ts     채널 하나 = Durable Object 하나. 소켓과 시계(초당 10틱)를 맡고 캐릭터를 저장
src/worker.ts   /ws/<채널> 웹소켓을 해당 채널로 연결
public/         브라우저: client.js(입력·그리기·창), art.js(도트 생성), audio.js(칩튠 합성)
tests/          규칙 테스트 (node tests/sim.mjs · node tests/party.mjs)
```

서버가 모든 판정을 합니다. 브라우저는 "이동/공격/구매" 같은 의도만 보내고, 서버는 위치·쿨타임·
골드·NPC와의 거리까지 검사한 뒤 초당 10번 각 플레이어에게 자기 주변 상황만 보내 줍니다.
캐릭터는 채널과 무관한 저장소에 보관되므로 어느 채널로 들어가도 같은 캐릭터입니다.

```bash
npx wrangler dev -c wrangler.local.jsonc   # http://localhost:8787 — 탭 두 개로 접속해 보세요
node tests/sim.mjs && node tests/party.mjs
```
