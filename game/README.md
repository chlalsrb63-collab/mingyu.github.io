# 루멘테일 온라인 (Lumentale Online)

GBA 시절의 도트 감성 + 2010년대 한국 모바일 RPG의 조작감(가상 조이스틱 · 자동사냥 · 강화)을 섞은
탑다운 2D 온라인 RPG입니다. 같은 채널에 접속한 플레이어끼리 실시간으로 만나 함께 사냥합니다.

- **플레이**: https://lumentale-online.higgsfield.app
- 그림 · 소리는 전부 코드로 생성합니다 (이미지/오디오 파일 없음).

## 게임 내용

| | |
| --- | --- |
| 직업 | 전사 · 궁수 · 마법사 (직업별 스킬 3개) |
| 지역 | 별빛 마을 → 바람초원 → 속삭임 숲 → 수정 동굴 (보스: 수정 군주 크리온) |
| 성장 | 레벨 30, 장비 4단계, 강화 +10, 촌장의 연속 의뢰 8개 |
| 온라인 | 채널 3개(채널당 40명), 채팅 · 말풍선, 함께 잡으면 모두 경험치, 치유 마법, 랭킹 |
| 조작 | 방향키/WASD · Space 공격 · 1 2 3 스킬 · Q/E 물약 · F 대화 · R 자동사냥 · 모바일 터치 |

## 구조

```
src/logic.js    게임 규칙 전부: 아이템·몬스터·스킬 표, 맵 4개, 전투·드랍·의뢰·강화 시뮬레이션
src/room.ts     채널 하나 = Durable Object 하나. 소켓과 시계(초당 10틱)를 맡고 캐릭터를 저장
src/worker.ts   /ws/<채널> 웹소켓을 해당 채널로 연결
public/         브라우저: client.js(입력·그리기·창), art.js(도트 생성), audio.js(칩튠 합성)
tests/sim.mjs   규칙 스모크 테스트 (node tests/sim.mjs)
```

서버가 모든 판정을 합니다. 브라우저는 "이동/공격/구매" 같은 의도만 보내고, 서버는 위치·쿨타임·
골드·NPC와의 거리까지 검사한 뒤 초당 10번 각 플레이어에게 자기 주변 상황만 보내 줍니다.
캐릭터는 채널과 무관한 저장소에 보관되므로 어느 채널로 들어가도 같은 캐릭터입니다.

## 로컬 실행

```bash
npx wrangler dev -c wrangler.local.jsonc   # http://localhost:8787 — 탭 두 개로 접속해 보세요
node tests/sim.mjs
```
