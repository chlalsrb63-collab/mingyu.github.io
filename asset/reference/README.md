# reference — 참고용 (배포 금지)

분위기·형태·색을 참고만 할 이미지를 넣는 곳입니다 (예: 인터넷에서 본 무기 아이콘 시트, "100 swords" 시트).
라이선스를 모르거나 재배포가 안 되는 그림이므로:

- 이 폴더의 파일은 **깃에 올라가지 않습니다** (`.gitignore`). 이 README만 올라갑니다.
- 여기 있는 그림을 **그대로 / 잘라서 / 따라 그려서** 게임에 넣지 않습니다.
- AI에게는 "이 시트처럼 다양한 실루엣(사브르, 시미터, 톱날, 물결날 …)" 같은 **아이디어**만 줍니다.
  모양·색은 우리 규칙(`ai/prompts/weapon-assets.md`)으로 새로 만듭니다.
