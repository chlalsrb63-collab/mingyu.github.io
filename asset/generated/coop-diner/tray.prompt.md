Prompt:
Create a 16x16 pixel-art icon of a wide serving tray for a cute isometric MMORPG kitchen mini-game (Juju Diner).
- Silhouette: A wide, low-profile horizontal platter (16px wide, 8px tall) with raised side grip handles and a broad, shallow rim framing a recessed non-slip slate bed.
- Perspective: 3/4 top-down icon view, lit from the top-left.
- Palette: ≤ 7 colors from the Tales Tales game palette (brass/wood rim #fff0a0, #e8bc4c, #9a6a40, #6a4434; slate bed #6e7a90, #464c66; 1px outer outline #2b2233).
- Rules: Crisp 1x pixel grid, binary alpha (transparent background), no anti-aliasing, no gradients, no pillow shading.
