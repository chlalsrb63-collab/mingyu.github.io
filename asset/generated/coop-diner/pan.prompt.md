# 프라이팬 (pan) — 16×16 협동 식당 도구 아이콘

Prompt:
Create a 16x16 pixel-art icon of a cast-iron frying pan for a cute isometric MMORPG kitchen mini-game (Juju Diner).
- Silhouette: A round, deep skillet basin in the upper-right with a long, sturdy diagonal wooden handle extending all the way to the lower-left corner.
- Perspective: 3/4 top-down icon view, lit from the top-left.
- Palette: ≤ 8 colors from the Tales Tales game palette (cast iron #373a46, #5a5e6c, #9a9eaa; wood grip #6a4434, #9a6a40, #c48e5c; hot oil glint #fff0a0; 1px outer outline #2b2233).
- Rules: Crisp 1x pixel grid, binary alpha (transparent background), no anti-aliasing, no gradients, no pillow shading.
